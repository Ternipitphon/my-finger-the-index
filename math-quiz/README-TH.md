# เว็บคิดเลขเร็ว 10 ข้อ

1. แตกไฟล์ ZIP ทั้งหมดก่อน
2. ดับเบิลคลิก **OPEN-QUIZ.cmd** บน Windows 10/11
3. เบราว์เซอร์จะเปิด **http://127.0.0.1:8787** อัตโนมัติ
4. เปิดหน้าต่างคำสั่งทิ้งไว้ระหว่างทดสอบ ปิดหน้าต่างนี้เมื่อต้องการหยุดเว็บ

ไม่ต้องติดตั้ง Node.js หรือ Python เว็บใช้เฉพาะ loopback ของเครื่องคุณ ไม่ได้เผยแพร่สู่อินเทอร์เน็ต หากไม่ใช้ Agent เปิด index.html โดยตรงก็เล่นได้ แต่ Browser Agent ต้องใช้ลิงก์ http ข้างบน

มีโจทย์บวก ลบ คูณ หาร 10 ข้อ ช่องกรอกคำตอบ ปุ่มส่งคะแนน เฉลยหลังส่ง จับเวลาตั้งแต่กรอกคำตอบแรก ล้างคำตอบ และสุ่มโจทย์ใหม่ ไม่มีการจำกัดเวลาและไม่ส่งข้อมูลออกจากเครื่อง

## คำสั่งทดสอบ Caprii

```text
/agent เปิด http://127.0.0.1:8787 อ่านโจทย์คณิต 10 ข้อ คำนวณจากโจทย์ในหน้าเว็บ กรอกคำตอบให้ครบ กดส่ง แล้วตรวจและรายงานคะแนน ห้ามอ่าน source code ของเว็บ
```

เลือกโฟลเดอร์ math-quiz เมื่อ Caprii ขอเลือกโฟลเดอร์ และอนุญาตการเปิดเว็บ กรอก คลิก และตรวจผลตามที่ตั้งใจ หน้าต่างเบราว์เซอร์ของ Agent จะแยกจาก Chrome ของคุณ

ตัวเปิดเว็บบน Windows ใช้ PowerShell ที่มาพร้อมระบบ ไม่เปลี่ยน execution policy และไม่ติดตั้งบริการถาวร ใน cloud ได้ทดสอบหน้าเว็บผ่าน Electron Browser จริง ส่วน OPEN-QUIZ.cmd ยังไม่ได้รันบน Windows จริง
