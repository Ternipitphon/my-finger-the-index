# Caprii 0.7.2 — ตัวติดตั้ง Windows x64

1. แตกไฟล์ ZIP ทั้งหมดก่อน อย่าเปิดสคริปต์จากในหน้าต่าง ZIP/WinRAR
2. ปิด Caprii รุ่นเก่าจากถาดระบบ
3. ดับเบิลคลิก **INSTALL-CAPRII.cmd** โดยให้ไฟล์ `Caprii-Setup.part*` ทุกส่วนอยู่ข้างกัน
4. สคริปต์ตรวจ SHA256 ทุกส่วนและตัวติดตั้ง แล้วเปิด **Caprii-Agent-Setup-0.7.2.exe** ให้ติดตั้ง
5. เปิด **Caprii Agent** จาก Desktop/Start Menu คลิกขวาตัวละคร → **Caprii 0.7.2** เพื่อดูรุ่น
6. ทดสอบ: คลิกขวาตัวละคร → **เปิดเว็บทดสอบ Caprii** เว็บจะเปิดเองใน browser ไม่ต้องติดตั้ง Node.js หรือเปิด server แยก ใช้ URL ที่แอปเปิดให้จริง

รุ่นนี้แก้ลากตัวละครเมื่อปิดแชต โดยอ่าน native cursor ขณะ idle และตรวจการกดปุ่มใหม่เมื่อ DOM press หาย ทดสอบจำลอง 20 รอบไม่ใช้ DOM events และ 30 รอบเดิม ยังไม่ได้ทดสอบเมาส์ Windows จริง

รวมการแก้อาการเชื่อมแล้วแต่แอปยังบอกไม่เชื่อม: ไม่ทิ้งสิทธิ์แท็บเพียงเพราะ heartbeat เกิน 8 วินาที Popup ตรวจแอปจริง ส่งคำสั่งจาก extension worker แทนตัวจับเวลาในหน้าเว็บ และฟื้นจากข้อผิดพลาดชั่วคราวโดยไม่กดคำสั่งที่ทำแล้วซ้ำ

ต้องอัปเดตทั้งแอปและส่วนขยาย 0.7.2: ปิด Caprii จากเมนู ออกจากโปรแกรม ในถาดระบบก่อนติดตั้ง เปิดโฟลเดอร์ส่วนขยายจากแอปใหม่ กด Reload ใน chrome://extensions เปิด Spotify ที่ล็อกอินแล้ว เชื่อมใหม่ด้วยรหัสรอบนี้หนึ่งครั้ง จากนั้นสั่ง เล่นเลย หรือ เล่น Liked Songs ไม่ต้องเชื่อมใหม่เพียงเพราะพักแท็บ

ผ่าน 206 app checks, 4 lab checks, 8 DOM browser cases และทดสอบ HTTP broker จริง + worker จำลอง + DOM จริงใน Electron ที่ปิด page timers ยังตรวจเพลงและเวลาเดินได้ ทดสอบสถานะ heartbeat ด้วยนาฬิกาจำลอง **ยังไม่ได้ทดสอบ Chrome/Spotify account/เสียงจริง/Windows จริง** ตัวติดตั้งไม่มีลายเซ็น ไม่มีการ publish เว็บไซต์

พื้นที่ว่างควรมีอย่างน้อย 2 GB สำหรับไฟล์ดาวน์โหลด ตัวติดตั้งที่รวมแล้ว และโปรแกรมติดตั้ง
