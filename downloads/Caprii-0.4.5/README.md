# ติดตั้ง Caprii Agent 0.4.5 บน Windows

1. ดาวน์โหลด repository ทั้งหมดเป็น ZIP: [กดดาวน์โหลด ZIP](https://github.com/Ternipitphon/my-finger-the-index/archive/refs/heads/main.zip)
2. คลิกขวา ZIP แล้วเลือก **Extract All / แตกไฟล์ทั้งหมด** ก่อน อย่าเปิดตัวติดตั้งจากภายใน ZIP
3. เปิดโฟลเดอร์ `downloads/Caprii-0.4.5`
4. ดับเบิลคลิก **INSTALL-CAPRII.cmd** จะตรวจ SHA-256 ของทั้ง 3 ส่วน รวมเป็นตัวติดตั้ง แล้วเปิดตัวติดตั้งให้
5. ตั้งค่า Gemini ตาม [คู่มือภาษาไทย](GUIDE-TH.md)

หาก GitHub ขอให้เข้าสู่ระบบ ให้ใช้บัญชีที่เข้าถึง repository นี้ได้

ไฟล์ `Caprii-Setup.part01`, `.part02`, `.part03` เป็นส่วนของตัวติดตั้ง **ต้องอยู่ด้วยกันทั้งสามไฟล์** ไม่ต้องเปิดทีละส่วน GitHub จำกัดขนาดไฟล์ จึงแบ่งตัวติดตั้งไว้เช่นนี้ สคริปต์ไม่ได้ดาวน์โหลดโปรแกรมอื่นหรือเปลี่ยน execution policy ของ Windows และจะไม่รันไฟล์หาก hash ไม่ตรง

หากไม่ต้องการให้สคริปต์เริ่ม installer อัตโนมัติ สามารถตรวจคำสั่งใน INSTALL-CAPRII.cmd ก่อนใช้งานได้ หลังรวมสำเร็จจะมี `Caprii-Agent-Setup-0.4.5.exe` อยู่ในโฟลเดอร์เดียวกัน

ตัวติดตั้งไม่มีลายเซ็นผู้พัฒนา และยังไม่ได้ทดสอบติดตั้ง/ควบคุม input บน Windows จริง ดู [ผลทดสอบและข้อจำกัด](VALIDATION.md) ก่อนใช้งาน

`Caprii-Agent-0.4.5-source.zip` คือ source พร้อมชุดทดสอบ ไม่จำเป็นต้องแตก source หากใช้ตัวติดตั้ง
