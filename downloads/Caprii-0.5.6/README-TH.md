# Caprii 0.5.6 — ตัวติดตั้ง Windows x64

1. แตกไฟล์ ZIP ทั้งหมดก่อน อย่าเปิดสคริปต์จากในหน้าต่าง ZIP/WinRAR
2. ปิด Caprii รุ่นเก่าจากถาดระบบ
3. ดับเบิลคลิก **INSTALL-CAPRII.cmd** โดยให้ไฟล์ `Caprii-Setup.part*` ทุกส่วนอยู่ข้างกัน
4. สคริปต์ตรวจ SHA256 ทุกส่วนและตัวติดตั้ง แล้วเปิด **Caprii-Agent-Setup-0.5.6.exe** ให้ติดตั้ง
5. เปิด **Caprii Agent** จาก Desktop/Start Menu คลิกขวาตัวละคร → **Caprii 0.5.6** เพื่อดูรุ่น
6. ทดสอบ: คลิกขวาตัวละคร → **เปิดเว็บทดสอบ Caprii** เว็บจะเปิดเองใน browser ไม่ต้องติดตั้ง Node.js หรือเปิด server แยก ใช้ URL ที่แอปเปิดให้จริง

รุ่นนี้รวมโค้ด DOM forms ล่าสุด (ข้อความ/dropdown/checkbox/radio), ตรวจค่ากลับและผลส่งที่แสดงช้า, Test Lab 7 เคส, ส่วนขยาย 0.5.6, และ Python/Agent Reach ที่ตรวจ checksum แล้ว ไม่ใช่แพตช์หรือซอร์สโค้ดอย่างเดียว

ทดสอบผ่าน 132 app tests, 3 lab checks, 7 เคส browser จริง และตรวจแพ็กเกจ ASAR/Windows x64/Python/ฟอนต์/ส่วนขยาย พร้อมเปิด Test Lab จาก ASAR จริงแล้ว **ยังไม่ได้ลองติดตั้งและควบคุมบน Windows จริง** ตัวติดตั้งยังไม่มีลายเซ็นดิจิทัล ไม่มีการ publish เว็บไซต์

พื้นที่ว่างควรมีอย่างน้อย 2 GB สำหรับไฟล์ดาวน์โหลด ตัวติดตั้งที่รวมแล้ว และโปรแกรมติดตั้ง
