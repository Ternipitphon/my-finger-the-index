# Caprii 0.5.5 + Agent Reach

ปิด Caprii เดิม ดาวน์โหลด ZIP ทั้ง repository แล้ว Extract All เข้า downloads/Caprii-0.5.5 และเปิด INSTALL-CAPRII.cmd โดยให้ไฟล์ part ทุกส่วนอยู่ข้างกัน สคริปต์ตรวจ SHA256 ก่อนเปิดตัวติดตั้ง Windows x64

## Agent Reach ที่เชื่อมแล้ว

- อ่านหน้าเว็บผ่าน Jina ค้นเว็บผ่าน Exa และข้อมูล/ค้นหา/คำบรรยายสาธารณะของ YouTube ผ่าน yt-dlp
- รวม Agent Reach 1.6.0 ที่ล็อก commit, Python 3.13.17 และ dependencies ตรวจ checksum แล้ว ไม่ต้องติดตั้ง Python หรือ uv เพิ่ม ไม่ต้องเชื่อม Chrome เพื่ออ่านลิงก์สาธารณะ
- วางลิงก์เดี่ยว หรือสั่ง “สรุปลิงก์ https://…” / “ค้นหาในเว็บ…” / “ค้นหาในยูทูป…” งานลิงก์มีเฉพาะเครื่องมืออ่านเว็บ ไม่อ่านจอ/ไฟล์อื่น ไม่เด้งหน้าติดตามงาน
- ใช้เมนู Agent Reach: ตรวจความพร้อม เพื่อตรวจตัวรัน การอ่านเว็บไซต์ยังขึ้นกับเครือข่าย/โควตา/คำบรรยายที่มีจริง
- ไม่คัดลอกบัญชีหรือคุกกี้ ไม่เปิดทุกช่องทางของ upstream ไม่รัน setup/update/login ไม่ถอดเสียงแบบมีค่าใช้จ่าย และไม่ข้ามการปิดกั้น ถ้ามีแค่ metadata หรือข้อความบางส่วนต้องรายงานตามนั้น ไม่อ้างว่าดูคลิปครบ
- ผ่าน 124 tests ของ Caprii, 4 tests ของตัวเชื่อมกับ parser จริง/ข้อมูลจำลอง และ real Electron chat IPC ไม่มีการอ้างว่าอ่านคลิปจริงสำเร็จใน cloud ที่ปิดกั้น YouTube ตัวรัน Windows ยังต้องตรวจบน Windows จริง
