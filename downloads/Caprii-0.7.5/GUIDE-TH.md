## Caprii 0.7.5 — ปุ่มคุยอยู่นิ่ง ไม่ตอบสนอง

เพิ่มทางสำรองเฉพาะปุ่ม “คุยกับฉัน” ตอนว่าง โดยอ่านขอบการกด–ปล่อยปุ่มเมาส์หลักจาก Windows helper เดิม แม้ไม่มี DOM mouse events ก็เรียกเปิดแชตได้ ต้องกดและปล่อยบนปุ่มเดิม ไม่กดติดจากการลากผ่าน ไม่ทำงานแทนปุ่มอนุญาต/ส่งข้อมูล และกันการเปิดซ้ำจาก native + DOM หรือคลิกที่มาช้าบนปุ่มเก่า

หยุดแอนิเมชันไล่ข้อความระหว่างกด เพราะการขึ้นบรรทัดใหม่ทำให้ตัวปุ่มขยับภายในกล่องได้ พร้อมแก้การปลดล็อกพื้นที่คลิกเมื่อไม่มี DOM mouseup ใช้เมนูคลิกขวา → คุย เป็นทางสำรองได้ตามเดิม

## Caprii 0.7.4 — ปุ่มคุยกับฉัน

แก้ปุ่มคุยตอนว่าง: ล็อกตำแหน่งและพื้นที่รับเมาส์ระหว่างกด ไม่ให้ข้อความหมดเวลาซ่อนปุ่มกลางการคลิก เมื่อกดแล้วแสดง “กำลังเปิดช่องคุย…” ทันทีระหว่างตรวจ AI ไม่เริ่มเปิดซ้อนจากการกดซ้ำ แสดงข้อผิดพลาดถ้าเชื่อมไม่ได้ และไม่เปิดแชตกลับเองหากผู้ใช้ปิดระหว่างรอ

## Caprii 0.7.3 — จำการเชื่อม Chrome

ในส่วนขยาย ติ๊ก **จำการเชื่อม Chrome และตามแท็บใช้งาน** แล้วอนุญาตเว็บไซต์ http/https ครั้งเดียว ใส่รหัส Caprii แล้วเชื่อม ระบบจำรหัสเฉพาะบนเครื่อง เชื่อมแท็บที่ใช้งานใหม่อัตโนมัติเมื่อปิดแท็บเดิม หรือปิด–เปิด Chrome ขณะที่แอป Caprii รอบเดิมยังเปิดอยู่ ไม่ต้องใส่รหัสทุกแท็บ

โหมดนี้เป็นตัวเลือก ต้องยอมรับสิทธิ์เว็บไซต์ใน Chrome ก่อน ควบคุมแท็บปัจจุบันครั้งละหนึ่งแท็บ ไม่อ่านทุกแท็บหรือฉีด DOM script เพียงเพราะสลับแท็บ ไม่ติดตามหน้าลับหรือ chrome:// และไม่ย้ายงานที่กำลังทำไปแท็บอื่น กด **ตัดการเชื่อมต่อ** เพื่อลบรหัสที่จำไว้และถอนสิทธิ์เว็บไซต์ หากปิด–เปิดแอป Caprii ใหม่ต้องเชื่อมรหัสใหม่หนึ่งครั้ง

อัปเดตแอปและส่วนขยายเป็น 0.7.3: ปิดแอปเก่าจากถาดระบบ ติดตั้งใหม่ กด Reload ส่วนขยายใน chrome://extensions เปิด Spotify ที่ล็อกอิน แล้วเปิด popup ติ๊กโหมดจำ Chrome และอนุญาตสิทธิ์ เมื่อเชื่อมแล้วสั่ง “เล่นเพลงใน Liked Songs”

## Caprii 0.7.2 — ลากได้เมื่อปิดแชต

เพิ่มการอ่านตำแหน่งเมาส์ขณะ idle เพื่อปรับพื้นที่คลิกโดยไม่พึ่ง mousemove ของหน้าต่างโปร่งใส และเริ่มจับจากขอบสัญญาณปุ่มหลักที่กดใหม่บนตัวละครได้เมื่อ DOM pointerdown หาย ไม่เริ่มจับจากการกดนอกตัวแล้วลากผ่าน หรือกดบนกล่องแชต ใช้ตัวอ่านปุ่ม Windows เดิม ไม่เพิ่มการฉีดเมาส์หรือจับภาพหน้าจอ

แตก ZIP ปิดแอปเก่าจากถาดระบบ แล้วรัน INSTALL-CAPRII.cmd ทดสอบลากโดยไม่เปิดแชตทั้งหลังเปิดแอปและหลังใช้งานไปสักพัก รุ่นนี้รวมการแก้ Spotify ของ 0.7.1 ด้วย

## Caprii 0.7.1 — เชื่อมแล้วแต่แอปยังบอกว่าไม่ได้เชื่อม

แก้สถานะไม่ตรงกัน: รุ่นก่อน popup จำว่าเชื่อมไว้ แต่แอปถือว่าหลุดเมื่อ heartbeat เกิน 8 วินาที และตัวส่งคำสั่งในหน้าเว็บหยุดเมื่อเจอข้อผิดพลาดชั่วคราว รุ่นนี้เก็บสิทธิ์การเชื่อมจนตัดจริง แยกสถานะยังรอสัญญาณออกจากยังไม่ได้อนุญาต และ popup ติดต่อแอปจริงก่อนแสดงว่าเชื่อมอยู่

ส่งคำสั่งผ่าน extension worker แทน page timers ที่อาจถูก Chrome ชะลอในแท็บเบื้องหลัง โหลด DOM bridge เมื่อจำเป็นและคืนการทำงานหลังเครือข่ายสะดุด ไม่ส่งคำสั่งที่รับไปทำแล้วซ้ำเมื่อ ack หาย ยังควบคุมเฉพาะแท็บและ origin ที่ผู้ใช้เลือก ไม่เพิ่มสิทธิ์ส่วนขยาย

**อัปเดตทั้งแอปและส่วนขยายเป็น 0.7.1:** ปิด Caprii จากถาดระบบก่อนติดตั้ง เปิดโฟลเดอร์ส่วนขยายจากแอปใหม่และกด Reload ใน chrome://extensions จากนั้นเปิดแท็บ Spotify ที่ล็อกอินแล้ว เชื่อมใหม่ด้วยรหัสของรอบนี้ครั้งเดียว แล้วพิมพ์ “เล่นเลย” การพักแท็บอย่างเดียวไม่ต้องกดเชื่อมใหม่ทุกคำสั่ง

เมื่ออยู่หน้า Liked Songs ที่ต้องการอยู่แล้วจะไม่โหลดหน้าใหม่ และการกด Play ไม่รอตัวจับเวลาในหน้าเว็บ การเปิดหน้าตัวเล่นเป็นคนละขั้นกับการยืนยันเพลงเล่น จึงยังตรวจสถานะและเวลาเดินตามเดิม หากเชื่อมผิดแท็บจะบอกชื่อเว็บไซต์ที่เชื่อมอยู่ ถ้ารุ่นส่วนขยายไม่ตรงจะแจ้งให้อัปเดตตรงจุด

## Caprii 0.7.1 — ค้นหา YouTube และเล่นเพลง Spotify

ตัวอย่างคำสั่งภาษาพูด:
- `เปิดyoutubeแล้วก็ค้นหาว่าlimbus` เปิด URL หน้าผลค้นหาโดยตรง ไม่ใช้ LLM เดาลิงก์และไม่เปิดคลิปแรกเอง
- `เปิด spotifyแล้วกดเล่นเพลงในliked song` เปิด Liked Songs ในแท็บ Spotify ที่เชื่อม แล้วกดเล่นและตรวจเวลาเพลงเดิน
- `เปิดเพลงชื่อ Harpy Hare ของ Yaelokre ใน Spotify` ค้นหาและเลือกชื่อ/ศิลปินตรงกัน ถ้าชื่อและศิลปินเดียวกันซ้ำหลายชุด ใช้ผลตรงอันดับสูงสุดของ Spotify; ถ้าคนละศิลปินจะถามเพิ่ม
- `เล่นเพลย์ลิสต์ Night Drive` ใช้ลิงก์ในคลังที่อ่านได้; `เล่นเพลงใน playlist นี้` ใช้เพลย์ลิสต์ที่เปิดในแท็บปัจจุบัน ถ้าระบุไม่ได้จะถามชื่อหรือลิงก์
- `เล่นเลย` ทำคำสั่ง Spotify รอบล่าสุดต่อในบทสนทนานี้ได้ ไม่ต้องพิมพ์รายละเอียดซ้ำ หลังเปลี่ยนไปทำงานอื่นจะไม่ย้อนมาเล่นเพลงเก่า

**ตั้งค่า Spotify ครั้งแรก:** ติดตั้ง 0.7.1 แล้วเปิดโฟลเดอร์ส่วนขยายจากเมนู Caprii และรีโหลด/ติดตั้งส่วนขยาย 0.7.1 ใน Chrome เปิด Spotify Web Player ล็อกอินด้วยตัวเอง และอนุญาตให้ Caprii ใช้แท็บนั้น ถ้ายังไม่เชื่อม แอปจะเปิดหน้าที่ต้องการและบอกว่ายังไม่ได้เล่น จากนั้นเชื่อมแท็บแล้วพิมพ์ “เล่นเลย” การค้นหา YouTube ไม่ต้องเชื่อมแท็บ

Spotify ใช้การควบคุม Web Player ไม่ใช้รหัสผ่าน คุกกี้ OAuth token หรือ Spotify API จากบัญชีผู้ใช้ ไม่มีการซื้อ Premium แก้เพลย์ลิสต์ กด Like หรือเปลี่ยนอุปกรณ์เล่นอัตโนมัติ การเล่นยังขึ้นกับสิทธิ์บัญชีและนโยบาย autoplay ของเบราว์เซอร์ อาจต้องกด Play ครั้งแรกในเว็บด้วยตัวเอง หากกดแล้วเวลาไม่เดินจะรายงานว่ายังยืนยันไม่ได้ ไม่มีการกด Play ซ้ำอัตโนมัติ Ctrl+Alt+Esc หยุดขั้นตอนที่เหลือ ส่วนเพลงที่เริ่มแล้วควบคุมจาก Spotify

ส่วนขยายคง session เมื่อย้ายหน้าในเว็บไซต์เดิมที่ผู้ใช้เชื่อม และตัดการเชื่อมต่อเมื่อออกคนละ origin เช่นหน้าเข้าสู่ระบบ ไม่เพิ่มสิทธิ์นอก activeTab/scripting/storage ทดสอบด้วย DOM จำลอง ไม่ใช่บัญชี Spotify หรือเสียงจริง

## Caprii 0.7.1 — ลากได้ช่วงแรกแล้วหยุดทำงาน

เพิ่มการอ่านสถานะปุ่มเมาส์หลักจริงผ่าน Windows helper เดิม (รองรับการสลับปุ่มสำหรับผู้ใช้ถนัดซ้าย) เพื่อใช้ประกอบการจบการลาก ไม่อาศัย pointerup/mouseup เพียงอย่างเดียว ถ้าข้อมูลปุ่มเก่าหรือ helper ไม่พร้อมจะถือว่ายังไม่ทราบสถานะ ไม่ตีความว่าได้ปล่อยปุ่มแล้วโดยอัตโนมัติ

เมื่อจับตัวละครจะยกเลิกเส้นทางเดินเล่นเก่าและเลื่อนการเดินอัตโนมัติออกไป ระหว่างกดค้างจะพักการเดินเล่นก่อนเริ่มลาก ทิ้งตัวอย่างเคอร์เซอร์ที่ตอบช้าจากการจับครั้งก่อน และตรวจการปล่อยปุ่มจริงแม้ไม่มีเหตุการณ์จากหน้าต่าง ทางย้ายสำรอง Ctrl+Alt+M ยังคงใช้ได้ ข้อมูลปุ่มอยู่ในเครื่อง ไม่เก็บลงดิสก์หรือส่งให้ AI

ทดสอบ sprite ลาก–ปล่อย 30 รอบต่อเนื่อง (แอนิเมชันน้อย 15 + เต็ม 15 รอบ) ด้วยสถานะปุ่มจำลอง รวมเหตุการณ์ปล่อยที่มาเร็วและเหตุการณ์ปล่อยที่หายไป ผ่าน 186 app tests แต่ยังไม่ได้ยืนยัน Windows helper และการจับจริงบน Windows

## Caprii 0.7.1 — คลิกติดแต่ลากไม่ขยับ

แก้การลากที่ได้รับ mousemove แต่ไม่มี pointermove รองรับทั้ง MouseEvent และ PointerEvent ไม่ปล่อยตัวละครเพียงเพราะหน้าต่างเสียโฟกัสหรือ mouse pointer capture หลุด และอ่านตำแหน่งเคอร์เซอร์โดยตรงทุกประมาณ 32 ms เฉพาะตอนกำลังจับ ล็อก native click-through ตลอดการจับ ไม่ให้การตรวจ hit/rearm สลับหน้าต่างเป็นคลิกทะลุระหว่างลาก

หากลากโดยตรงยังมีปัญหา: คลิกขวา **ไอคอน Caprii ในถาดระบบข้างนาฬิกา** → **จับย้ายตัวละคร — ขยับเมาส์แล้วคลิกวาง** หรือ **Ctrl+Alt+M** ไม่ต้องกดค้าง คลิกซ้ายเพื่อวางหรือคลิกขวา/Ctrl+Alt+Esc เพื่อยกเลิก เลือกได้เฉพาะหน้าจอที่ตัวละครอยู่ มี timeout 30 วินาทีเพื่อไม่ให้ติดโหมดจับ

คำสั่ง “อ่านแท็บที่เชื่อมต่อก่อน บอกค่าปัจจุบัน…ยังไม่ต้องกรอกหรือกดส่ง” จะเข้าตัวอ่าน DOM จริง ส่วน “ช่องชื่อนั่นใส่แมวบิน…” จะเข้า Agent สำหรับแท็บที่เชื่อม ไม่ตอบจากแชตเปล่า ถ้ายังไม่เชื่อมให้เปิดเมนู เชื่อมแท็บ Chrome… และอนุญาตจากส่วนขยายก่อน แอปจะบอกตรง ๆ ว่ายังไม่ได้อ่าน/กรอก

ผลยังไม่ยืนยันจะรายงานสถานะจากเครื่องมือ ไม่ใช้คำกล่าวว่า “กรอกแล้ว” ของโมเดลเป็นหลักฐาน อ่านอย่างเดียวจะโชว์ค่าที่อ่านได้จริงและบอกว่ายังไม่ได้กรอก/ส่ง หลังส่งต้องตรวจ acknowledgment ใหม่ ไม่คลิกส่งซ้ำเพื่อแก้การตรวจที่ยังไม่เสร็จ

## ความยาวคำตอบ / คำพูด

คลิกขวาตัวละคร → **ความยาวคำตอบ / คำพูด** เลือก **สรุปสั้น — 1–3 ประโยค**, **สมดุล**, หรือ **ละเอียด** ค่าเริ่มต้นสรุปสั้น มีผลกับแชต รูป หน้าจอ และ Agent summary และจำค่าหลังปิด–เปิดแอป ขอ “อธิบายละเอียดทีละขั้นตอน” เป็นรายครั้งได้โดยไม่เปลี่ยนค่าหลัก ไม่ตัด JSON/โค้ด/สูตรเพื่อให้สั้น ความยาวสุดท้ายขึ้นกับโมเดล

“ข้อนี้ตอบอะไร” จะอ่านโจทย์ปัจจุบันจากแท็บที่เชื่อมหรือจับภาพหน้าจอหลังอนุญาต คำนวณตรวจเมื่อเป็นตัวเลข แล้วสรุปโดยไม่กรอกหรือส่ง ถ้าระบุห้ามดูจอจะขอโจทย์ที่พิมพ์หรือรูปแนบแทน

Chrome: ถ้าเปิด Test Lab ผ่าน file:// ให้ใช้เมนู **เปิดเว็บทดสอบ Caprii** แล้วเชื่อมแท็บ http ที่แอปเปิด ถ้าแอปไม่พร้อม/รหัสไม่ตรง/session หมดอายุ จะแจ้งเฉพาะสาเหตุ ไม่รวมเป็นข้อความผิดพลาดเดียว

## บุคลิกและรูปภาพ

บุคลิกกวน ๆ พูดตรง มั่นใจและห่วงผู้ใช้ ได้แรงบันดาลใจจากรีเบคก้า เปิดเป็นค่าเริ่มต้นทั้งโปรไฟล์ใหม่และเดิม ปิดได้ที่เมนู **บุคลิกกวน ๆ แบบรีเบคก้า** ยังคงความถูกต้อง การอนุญาตเครื่องมือ และคำสั่งห้ามส่ง ไม่ใช่ตัวละครจริงหรือผลงานทางการ

ในแชต กด **📎 แนบรูป** เลือก PNG/JPEG/WebP หรือคัดลอกรูปแล้ววางด้วย **Ctrl+V** จะเห็นภาพตัวอย่างก่อนส่ง ใส่คำถามแล้วกดส่ง หรือส่งเฉพาะรูปก็ได้ กด ✕ บนรูปเพื่อนำออก รูปส่งให้ provider/model ที่เลือกเมื่อกดส่ง ไม่ใช่การจับภาพหน้าจอ

รองรับไฟล์ไม่เกิน 15 MB และภาพไม่เกิน 40 ล้านพิกเซล ย่อด้านยาวไม่เกิน 1600 px ก่อนส่ง รูปอยู่ในหน่วยความจำชั่วคราว ไม่บันทึกพิกเซลลงประวัติแชต หากโมเดลไม่รองรับภาพจะแจ้งและเก็บรูปไว้ให้เปลี่ยนโมเดล/ลองใหม่ ไม่แกล้งสรุปจากข้อความล้วน Claude Code mode ยังไม่รองรับรูปผ่านช่องนี้ เลือก Gemini หรือโมเดล vision ที่รองรับแทน

Test Lab เพิ่มเคสอ่านรูปเป็น 8 เคส บุคลิกเป็นลักษณะคำตอบของโมเดล ไม่ใช่หลักฐานว่าได้ทำงานสำเร็จ

## ติดตั้งและเริ่มใช้

ปิด Caprii ตัวเดิมก่อนติดตั้ง ดาวน์โหลด ZIP เฉพาะรุ่น 0.7.1 แล้วแตกไฟล์ เปิด `INSTALL-CAPRII.cmd` โดยให้ไฟล์ part ทั้งหมด อยู่ข้างกัน สคริปต์ตรวจ SHA256 ทุกส่วน รวมตัวติดตั้ง แล้วเปิดติดตั้ง Windows 10/11 x64 ไม่ต้องติดตั้ง Node.js

หากขึ้น Error opening file for writing ให้ปิด Caprii จากถาดระบบหรือ Task Manager แล้ว Retry อย่ากด Ignore ตัวติดตั้งไม่มีลายเซ็นดิจิทัล และการติดตั้งจริงบน Windows ยังต้องตรวจบนเครื่องคุณ

เมนูอยู่ที่คลิกขวาตัวละครหรือไอคอนถาดระบบ กด Ctrl+Alt+C เพื่อซ่อน/แสดง และ Ctrl+Alt+Esc เพื่อหยุดงานทันที

## เว็บทดสอบในตัว (0.7.1)

คลิกขวาตัวละคร → **เปิดเว็บทดสอบ Caprii** แอปเปิดเว็บใน browser และเปิด server เฉพาะในเครื่องให้เอง ไม่ต้องติดตั้ง Node.js หรือ Python เพิ่ม ใช้ URL ที่แอปเปิดให้จริงซึ่งอาจมีพอร์ตต่างจาก 5173 เลือกเคส เชื่อมแท็บกับส่วนขยาย แล้วคัดลอกคำสั่งไปบอก Caprii ปิดแอปแล้ว server จะหยุด

## Agent Reach ใน Caprii (ตั้งแต่ 0.5.5)

รวม Agent Reach 1.6.0 จาก https://github.com/Panniantong/agent-reach ที่ commit `21f0ead1dfc9d0fc8262f28adbfbff93219b998e` ภายใต้ MIT พร้อม Python 3.13.17/เครื่องมือที่จำเป็นในตัวติดตั้ง Windows ไม่ต้องติดตั้ง Python/uv หรือใช้บัญชีเพิ่มเพื่อใช้ส่วนที่เชื่อมนี้

- วาง URL เดี่ยวในแชต หรือสั่ง **อ่าน/สรุปลิงก์ https://…** เพื่ออ่านแหล่งข้อมูลจริง งานลิงก์จำกัดเครื่องมือไว้ที่ข้อมูลสาธารณะ ไม่เข้าถึงจอ/ไฟล์อื่น ไม่แสดงหน้าติดตามงาน
- สั่ง **ค้นหาในเว็บ…** หรือ **ค้นหาในยูทูป…** เพื่อค้นไม่เกิน 5 ผลลัพธ์ต่อครั้ง
- YouTube: อ่านชื่อ/คำอธิบาย และดึงคำบรรยายสาธารณะ โดยเลือกไทยก่อนอังกฤษ ไม่มีคำบรรยายต้องบอกตรง ๆ ไม่อ้างว่าได้ดูวิดีโอจากแค่ชื่อ/คำอธิบาย หากข้อความถูกตัดต้องรายงานว่าเป็นสรุปบางส่วน
- เว็บทั่วไปส่ง URL ให้ **Jina Reader (r.jina.ai)** และส่งคำค้นเว็บให้ **Exa (mcp.exa.ai)** ข้อความที่ได้จะส่งให้ผู้ให้บริการ AI ของคุณเพื่อสรุป YouTube ใช้ yt-dlp ติดต่อโดยตรง อาจมีโควตา/ข้อจำกัดของเว็บไซต์
- เชื่อมเฉพาะอ่านเว็บ/ค้นเว็บ/ข้อมูลและคำบรรยาย YouTube ไม่ได้เปิดทุกช่องทางของ Agent Reach ไม่คัดลอกคุกกี้/บัญชี Chrome ไม่เปิด login/setup/update อัตโนมัติ ไม่ถอดเสียงผ่านบริการที่คิดค่าใช้จ่าย และไม่เปลี่ยนวิธีเพื่อข้ามการปิดกั้นของเว็บไซต์
- ตรวจตัวรันได้ที่เมนู **Agent Reach: ตรวจความพร้อม** การตรวจพร้อมไม่ยืนยันว่าทุกเว็บเข้าถึงได้ หากติดนโยบายเครือข่าย/403/429/ไม่มีคำบรรยาย ระบบต้องรายงานข้อจำกัด ไม่แต่งเนื้อหา
- โหมดไม่ถามเดิมใช้กับการอ่านข้อมูลสาธารณะนี้ได้เมื่อคุณเปิดเองในรอบนั้น การแก้ไฟล์/รันสคริปต์ยังขอแยก

สำหรับผู้ build จากซอร์ส: รัน `npm run reach:prepare` ก่อน build Windows สคริปต์ดาวน์โหลด Python จาก NuGet ทางการและ dependencies ที่ล็อกรุ่น ตรวจ SHA512/SHA256 ทุกไฟล์ตาม `integrations/agent-reach/runtime-lock.json` ไม่ใช้แพ็กเกจชื่อ agent-reach จาก PyPI ไฟล์ runtime ที่สร้างอยู่ใน vendor-runtime และไม่รวมในซอร์ส ZIP ใช้ `CAPRII_REACH_PYTHON` เลือก Python ใน development ที่มี dependencies ตรง constraints ของ upstream ได้

ทดสอบตัวรันจริงบน Linux และ parser ของ upstream ด้วยข้อมูลจำลอง พร้อมเส้นทางแชต/สิทธิ์ใน Electron แล้ว การเข้าถึงคลิป YouTube ที่คุณส่งมาก่อนหน้ายังไม่สำเร็จจาก cloud เนื่องจากเครือข่ายปฏิเสธ ไม่อ้างว่าอ่านคลิปนั้นแล้ว ตัวรัน Windows ที่รวมไว้ยังไม่ได้ทดสอบบนเครื่อง Windows จริง

## ควบคุมจอ เปิดไฟล์และเกม และซ่อนหน้าติดตามงาน (0.5.5)

- ไม่แสดงหน้าต่างติดตามงานแยกเป็นค่าเริ่มต้น สถานะอยู่ในแชต ต้องการรายละเอียดให้เปิดเมนู **แสดงหน้าต่างติดตามงาน** ก่อนเริ่มงานใหม่ ปุ่มหยุดและ Ctrl+Alt+Esc ยังทำงาน
- **Windows UI Automation**: อ่านชื่อ/ชนิดปุ่มและค่าช่องที่ไม่ใช่รหัสผ่าน ใช้ ValuePattern กรอก/อ่านกลับ และ InvokePattern เรียกปุ่มโดยไม่ขยับเมาส์ ตรวจ handle, process ID/เวลาเริ่ม, ชื่อหน้าต่าง และ runtime ID ของปุ่มก่อนใช้ ข้อมูลเก่ากว่า 30 วินาทีใช้ไม่ได้ การเรียกปุ่มไม่ใช่หลักฐานว่างานเสร็จ ต้องตรวจค่าหรือข้อความตอบรับใหม่
- DOM ของส่วนขยาย Chrome ยังเป็นวิธีหลักสำหรับแท็บที่เชื่อม เพราะอ่านค่าช่อง/ปุ่มของเว็บได้ตรงกว่า UIA หากโปรแกรม/เกมไม่เผยช่องที่เข้าถึงได้ จึงใช้ภาพและคีย์บอร์ด/เมาส์ ขยายปุ่มเดี่ยว A–Z, 0–9 และ F1–F12 แล้ว ไม่รองรับการกดค้างเล่นต่อเนื่องหรือการควบคุมเกมทุกชนิด ไม่ข้ามสิทธิ์ Windows/UAC หรือระบบป้องกันของเกม
- สั่ง **ค้นหาไฟล์รายงานแล้วเปิดให้หน่อย** หรือ **เปิดเกม Limbus Company**: ค้นหาชื่อใน Desktop, Documents, Downloads, Start Menu (ลึกไม่เกิน 4 ชั้น, ไม่เกิน 6,000 รายการ/40 ผลลัพธ์) ไม่สแกนทั้งไดรฟ์ ไม่อ่านเนื้อหา ไม่ตาม symlink และไม่เปิดไฟล์สคริปต์/ตัวติดตั้งโดยตรง เลือกจาก ID ของผลค้นหาที่เพิ่งพบ ตรวจว่าไฟล์ไม่เปลี่ยนก่อนเปิด ทางลัด .lnk/.url เปิดผ่าน Windows และอาจเรียกโปรแกรม/Steam ต้องติดตั้งเกมและมีทางลัดอยู่แล้ว ไม่ถือว่าเกมเปิดสำเร็จจนกว่าจะตรวจหน้าต่าง
- เมนู **โหมดไม่ถาม: จอ/เว็บ/เปิดไฟล์และโปรแกรม (จนปิด Caprii)** เปิดเองครั้งเดียวในรอบนั้นเพื่อใช้ DOM/UIA/คีย์บอร์ด/เมาส์/ค้นหาชื่อและเปิดรายการต่อเนื่อง ไม่บันทึกสิทธิ์ข้ามการเปิดโปรแกรม สคริปต์และการแก้เนื้อหาไฟล์ยังขอแยก ถ้าปิดโหมด/กดหยุดจะหยุดงานปัจจุบัน
- ส่วนขยายแสดงชื่อแท็บที่เลือก และจำรหัสเฉพาะรอบ browser session เพื่อเติมช่องให้อีกครั้งหลังนำทาง ไม่ได้เชื่อมทุกเว็บเอง กดส่วนขยายในแท็บปัจจุบันแล้ว **อนุญาตให้ใช้แท็บนี้** เพื่อเชื่อมใหม่ หากปิดเปิด Caprii ต้องใช้รหัสใหม่ ปุ่มตัดการเชื่อมต่อล้างรหัสที่จำไว้

ทดสอบส่วนขยายบน Google Chrome จริงบน Linux กับฟอร์มท้องถิ่นแล้ว แต่ยังไม่ได้ทดสอบ UI Automation, การเปิดไฟล์/ทางลัดจริง, คีย์เกม หรือ Limbus บน Windows ของผู้ใช้ ภาพหน้าจอที่ส่งมาไม่ได้ให้สิทธิ์เข้าถึงเครื่องของคุณ

## เพิ่มคุณภาพคำตอบและเลือกโมเดล

รุ่น 0.5.5 เปิดโหมด **โฟกัสงาน: ตอบตามข้อเท็จจริงและความยาก** เป็นค่าเริ่มต้น ตอบไทย กระชับเมื่อคำถามง่าย และอธิบายงานยากได้เกิน 3 ประโยค ไม่เพิ่มความจำข้ามงาน ไม่อ้างว่าทำสิ่งที่ยังไม่ได้ทำ ปิดตัวเลือกนี้เพื่อกลับไปใช้บทบาทตัวละครในการสนทนา

คลิกขวา → **โหมดคุณภาพโมเดล** → **สมดุล** (Flash ที่ไม่ใช่ Lite) หรือ **คุณภาพสูง** (Pro ที่มีในรายชื่อ API; หากไม่มีจะเสนอ Flash ที่ไม่ใช่ Lite) ตรวจชื่อโมเดลแล้วเลือก **ทดสอบแล้วใช้** จะส่งคำถามทดสอบสั้นหนึ่งครั้ง และบันทึกเมื่อได้คำตอบไทยเท่านั้น หากยกเลิกไม่ส่งคำขอ หากล้มเหลวเก็บโมเดลเดิม เลือกเฉพาะโมเดล stable ที่ API ของบัญชีส่งกลับมา ไม่สร้างชื่อรุ่นเอง

การทดสอบนี้ยืนยันเพียงว่าโมเดลตอบได้ ไม่ใช่การวัดความแม่นยำ การใช้ API มีโควตา/ราคาแยกจาก Gemini บนเว็บ และไม่ได้ให้เครื่องมือค้นหา/ความสามารถทุกอย่างของเว็บโดยอัตโนมัติ Caprii จึงไม่รับประกันว่าฉลาดเท่ากันทุกงาน ไม่สลับไป Pro เองเมื่อ Lite ไม่ว่าง หรือกลับไป Lite เมื่อ Pro ไม่ว่าง หากโมเดลที่เลือกหายจากรายชื่อ ให้เลือกและทดสอบใหม่ โหมดคุณภาพรอคำตอบแชตได้สูงสุด 60 วินาที โดยยังหยุดได้

## ภาษาไทยและเสียงพูด

บทพูดสำเร็จรูป 477 รายการ เมนูหลัก และคำตอบตั้งเป็นไทย คงเลขอารบิก ชื่อโปรแกรม โค้ด URL และรายละเอียดเทคนิคตามจริง หากโมเดลตอบเป็นอังกฤษล้วน จะขอเรียบเรียงไทยเพิ่มได้หนึ่งครั้ง ภายใต้งบคำขอ/เวลาที่จำกัด ไม่แสดงคำตอบอังกฤษล้วนเป็นคำตอบทั่วไปเมื่อแปลงไม่สำเร็จ

เปิด **อ่านบทพูดด้วยเสียงไทย** จากเมนูได้ ต้องมีเสียงไทยแบบ local ติดตั้งในระบบ หากไม่มีเสียงไทย จะแสดงข้อความไทยแทน ไม่ใช้เสียงอังกฤษหรือบริการอ่านเสียงออนไลน์แทน ปุ่มปิดเสียงยังมีผล

## เชื่อม Chrome เพื่อกรอกช่องโดยตรง

1. คลิกขวา Caprii → **เปิดโฟลเดอร์ส่วนขยาย Chrome**
2. เปิด `chrome://extensions` เปิด Developer mode → Load unpacked → เลือกโฟลเดอร์ที่เปิดในข้อ 1
3. คลิกขวา Caprii → **เชื่อมแท็บ Chrome…** → คัดลอกรหัส
4. เปิดแท็บโจทย์ คลิกส่วนขยาย Caprii วางรหัส → **อนุญาตให้ใช้แท็บนี้**
5. สั่ง **ทำโจทย์บนหน้าเว็บนี้ กรอกคำตอบ แล้วกดส่งให้หน่อย**

ส่วนขยายอ่านช่อง/ปุ่มจาก DOM ของแท็บที่เลือก จึงลดการเดาพิกัดและรองรับการอ่านค่ากลับหลังกรอก หากช่อง read-only จะรายงานให้ใช้แป้นคำตอบบนเว็บ กรอกไม่ติดหรือค่าถูกล้างจะไม่รายงานว่าตรวจผ่าน

รหัสเชื่อมมีอายุเฉพาะรอบที่เปิด Caprii ไม่ใช่คีย์ Gemini ไม่ส่งรหัสในแชต ส่วนขยายไม่ขอสิทธิ์อ่านทุกเว็บไซต์ ข้อมูลแท็บที่เลือกอาจส่งให้ผู้ให้บริการ AI ที่ตั้งไว้ ตัดการเชื่อมต่อจากส่วนขยายได้ หากรีโหลด/เปลี่ยน URL/ปิดแท็บหรือเปิด Caprii ใหม่ ต้องเชื่อมใหม่ เมื่ออัปเดต Caprii ให้ Reload ส่วนขยายใน chrome://extensions ด้วย

ฟังก์ชันนี้ไม่ควบคุมแท็บอื่น หน้า chrome:// หน้าไฟล์ในเครื่อง iframe ข้ามเว็บไซต์ ช่องรหัสผ่าน หรืออัปโหลดไฟล์ ไม่ข้าม CAPTCHA และไม่เปลี่ยนสิทธิ์ผู้ดูแลระบบ

## ดูจอแล้วหาคำตอบ

คำสั่ง “ดูจอแล้วหาคำตอบ” เรียกเครื่องคิดเลข/ตัวแก้ปริศนาแทนการบรรยายภาพอย่างเดียว เป็นคำสั่งหาคำตอบ ไม่กรอกหรือส่งเว้นแต่ขอเพิ่ม เช่น “หาคำตอบแล้วกรอกและกดส่ง”

ภาพจับโดยซ่อนหน้าต่างภายใน Caprii ชั่วคราวแล้วคืนกลับ หากหน้าต่างรหัสเชื่อมต่อเปิดอยู่จะไม่จับภาพ เพื่อไม่ให้ AI อ่านบทพูดเก่าของตัวเอง ไม่ส่งประวัติงานเก่าที่ไม่เกี่ยวข้องไปกับคำถามดูจอแต่ละครั้ง คำตอบทั่วไปและสรุปงานใช้ภาษาหลักที่เลือก (ไทยหรือ English) และตัวตรวจถ้อยคำเดียวกัน หากตรวจพบถ้อยคำไม่เหมาะสมจะให้เรียบเรียงใหม่หนึ่งครั้ง ถ้ายังไม่ผ่านจะไม่แสดงข้อความนั้น

## คำสั่งสั้นและการแก้ปัญหา

ใช้ “ทำข้อนี้ให้หน่อย” เพื่ออ่านโจทย์ปัจจุบัน คำนวณ และกรอก ถ้าขอวิธีทำ เช่น “ทำโจทย์ข้อนี้ยังไง” จะอธิบายโดยไม่กรอกหรือส่ง คำสั่ง “ส่งเลย/ส่งให้หน่อย/ทำต่อ” ใช้บริบทคำสั่งในแชตที่เปิดอยู่และอ่านสถานะปัจจุบันใหม่ หากไม่มีบริบทชัดเจนจะถามกลับ ไม่เพิ่ม Memory หรือเก็บคำตอบเดิมข้ามงาน

เมื่อช่อง read-only จะอ่านหน้าใหม่และใช้แป้นบนเว็บได้ การตรวจค่าที่ตรงกับช่องเดิมเท่านั้นจึงยืนยันว่าขั้นตอนที่พิมพ์ไม่สำเร็จได้รับการแก้แล้ว สถานะจะแสดง “กำลังตรวจและแก้” และ “แก้แล้วและตรวจผ่าน” โดยยังเก็บร่องรอยข้อผิดพลาดเดิม

คำสั่งเดิมที่ล้มเหลวจะไม่ถูกส่งซ้ำเกิน 2 ครั้ง หากผลการคลิก/พิมพ์ไม่แน่ชัดหรือแท็บไม่ตอบ จะหยุดส่งคำสั่งเปลี่ยนข้อมูลซ้ำในงานนั้น ให้ตรวจสถานะหรือให้ผู้ใช้ตัดสินใจ ข้อความตอบรับที่มีอยู่ก่อนส่งจะไม่ยืนยันการส่งครั้งใหม่

## พิมพ์คำสั่งด้วยเสียงบน Windows

ในช่องแชตปกติ กดปุ่ม 🎤 แล้วอ่านคำอธิบายและเลือกเริ่ม เลือกภาษาแป้นพิมพ์เป็นไทยก่อน แอปส่งคำขอ Win+H เฉพาะเมื่อช่องแชตของ Caprii อยู่ด้านหน้า ไม่เริ่มจากคำสั่งของโมเดล ไม่ใช้กับช่องคีย์/รหัสผ่าน และไม่เริ่มขณะงาน AI กำลังทำอยู่

Windows เป็นผู้รับและประมวลผลเสียงตามการตั้งค่าระบบ ซึ่งอาจใช้บริการออนไลน์ของ Microsoft แอปไม่บันทึกเสียงเอง เสียงที่รู้จำได้จะลงในช่องแชต **ตรวจข้อความ หยุดไมค์ด้วย Win+H หรือแถบ Windows แล้วกดส่งเอง** ไม่มีการส่งให้ AI อัตโนมัติ

Ctrl+Alt+Esc หยุดงาน AI แต่ไม่ได้ปิดไมค์ของ Windows ฟีเจอร์นี้ต้องอาศัย Windows Voice Typing/ภาษาไทยที่ระบบรองรับ หากปุ่มไม่ทำงาน ให้คลิกช่องแล้วลอง Win+H เอง ปุ่มไม่แสดงบนระบบอื่น การรับเสียงจริงและ shortcut ยังไม่ได้ทดสอบบน Windows ใน cloud นี้

## การทำโจทย์และตรวจผล

ใช้เครื่องคิดเลขจำนวนตรรกยะจริงและตัวแก้ปริศนาตรวจเลข ไม่ใช้คำตอบเดา ปริศนาเลขใช้เลขที่เห็นแต่ละตัวครั้งเดียว รองรับ + − × ÷ วงเล็บ และต่อเลขเฉพาะกติกาที่อนุญาต หากไม่พบคำตอบจะรายงานขอบเขต ไม่แต่งเลขใหม่

คำสั่งกรอก/ส่งต้องมีหลักฐานเรียกเครื่องมือครบ การคำนวณสำเร็จอย่างเดียวไม่ถือว่างานจบ ตรวจค่าช่องหลังกรอก และตรวจข้อความตอบรับหลังส่ง การตรวจชื่อหน้าต่างหรือส่งคลิกได้ไม่ยืนยันว่าเว็บรับคำตอบแล้ว หากติดขัดจะรายงานงานที่ยังไม่ทำ

## การยืนยันและหยุดงาน

ค่าเริ่มต้นถามก่อนทำงาน หากต้องการลดการถาม เปิด **โหมดไม่ถาม: ดูจอ/คลิก/พิมพ์/เปิดเว็บ (จนปิด Caprii)** จากเมนูด้วยตัวเอง สิทธิ์นี้อยู่เฉพาะรอบที่เปิดโปรแกรม ไม่เก็บข้ามครั้ง ไม่เปิดการดูจอเป็นพื้นหลัง ไฟล์/สคริปต์และการเปลี่ยนกติกาโจทย์ยังยืนยันแยก แต่ละงานไม่เกิน 5 นาที หยุดจากหน้าต่างติดตามงานหรือ Ctrl+Alt+Esc ได้

## AI และความจำ

ตั้งผู้ให้บริการและคีย์ผ่านหน้า setup ของแอป ไม่ใส่คีย์ในซอร์สหรือแชต การเก็บคีย์ใช้ secure storage ของระบบหรือ environment binding ที่รองรับ ไม่รับประกันโควตา/ความพร้อมของผู้ให้บริการ โมเดลที่รองรับภาพจำเป็นสำหรับการอ่านจอแบบภาพ แต่ทาง Chrome DOM อ่านข้อความ/ช่องโดยตรงได้

ไม่ได้เพิ่ม Memory ข้ามงาน ประวัติแชตไม่บันทึกข้ามการเปิดโปรแกรมเป็นค่าเริ่มต้น การเชื่อมแท็บและรหัสอยู่ในหน่วยความจำเฉพาะรอบ
