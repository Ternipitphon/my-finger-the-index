# ติดตั้ง Caprii Agent 0.4.9 บน Windows

1. ปิด Caprii ตัวเก่าจากไอคอนถาดระบบก่อนติดตั้ง เพื่อไม่ให้ไฟล์ Caprii.exe ถูกล็อก
2. ดาวน์โหลด ZIP ทั้ง repository แล้วคลิกขวา Extract All (แตกไฟล์ทั้งหมด)
3. เข้า downloads/Caprii-0.4.9 ในโฟลเดอร์ที่แตกแล้ว
4. เปิด INSTALL-CAPRII.cmd โดยให้ไฟล์ part01, part02, part03 อยู่ด้วยกัน สคริปต์จะตรวจ SHA256 ทุกส่วน รวมไฟล์ และเปิดตัวติดตั้ง
5. ทำตามตัวติดตั้ง แล้วเปิด Caprii Agent

ถ้าขึ้น Error opening file for writing ให้ปิด Caprii ทุกตัวจาก Task Manager แล้วกด Retry อย่ากด Ignore

## สิ่งที่เปลี่ยน

- ครั้งแรกที่ดูจอหรือควบคุมหน้าต่าง เลือก “อนุญาตตลอดงานนี้” เพื่อไม่ต้องยืนยันทุกภาพหรือทุกคลิกในขอบเขตเดิม
- สิทธิ์ไม่เกิน 5 นาที หมดเมื่อจบงานหรือกดหยุด เปลี่ยนจอ/หน้าต่าง/ตัวโปรแกรมจะถามใหม่ ไฟล์ สคริปต์ และการทำงานนอกขอบเขตยังขออนุญาตแยก
- สิทธิ์ควบคุมรวมการพิมพ์ คลิก และส่งแบบฟอร์ม พร้อมส่งภาพจอและชื่อหน้าต่างให้ผู้ให้บริการ AI
- ตัวละครเริ่มกลางจอ สุ่มเดินเลื่อน ขยับ และแสดงข้อความไทยตอนว่าง หยุดสุ่มระหว่างแชตหรืองาน ไม่สุ่มใช้เมาส์จริงหรือเปิดโปรแกรม
- ปิดการเดินสุ่มจากเมนูตัวละครได้ ปฏิบัติตามการตั้งค่าลดภาพเคลื่อนไหว

ผ่านการทดสอบ 68 ข้อและ Electron GUI บน Linux การติดตั้ง/ควบคุมเมาส์จริงบน Windows ยังต้องตรวจบนเครื่อง Windows ตัวติดตั้งไม่มีลายเซ็นดิจิทัล

ซอร์สปัจจุบันอยู่ที่ ../../caprii และ Caprii-Agent-0.4.9-source.zip


แก้คำสั่ง “ทำโจทที่อยู่บนหน้าให้หน่อย” และ “ช่วยทำข้อที่อยู่บนหน้านี้ให้หน่อย” ให้เริ่ม Agent ผ่านการขออนุญาตดูจอ ไม่ตอบเป็นแชตอย่างเดียว ยังคงตรวจคำตอบด้วยเครื่องคิดเลขก่อนกรอก
