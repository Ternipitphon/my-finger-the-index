# Caprii 0.5.4 — คู่มือภาษาไทย

## ติดตั้งและเริ่มใช้

ปิด Caprii ตัวเดิมก่อนติดตั้ง ดาวน์โหลด ZIP ทั้ง repository แล้วแตกไฟล์ เปิด `downloads/Caprii-0.5.4/INSTALL-CAPRII.cmd` โดยให้ไฟล์ part01–03 อยู่ข้างกัน สคริปต์ตรวจ SHA256 ทุกส่วน รวมตัวติดตั้ง แล้วเปิดติดตั้ง Windows 10/11 x64 ไม่ต้องติดตั้ง Node.js

หากขึ้น Error opening file for writing ให้ปิด Caprii จากถาดระบบหรือ Task Manager แล้ว Retry อย่ากด Ignore ตัวติดตั้งไม่มีลายเซ็นดิจิทัล และการติดตั้งจริงบน Windows ยังต้องตรวจบนเครื่องคุณ

เมนูอยู่ที่คลิกขวาตัวละครหรือไอคอนถาดระบบ กด Ctrl+Alt+C เพื่อซ่อน/แสดง และ Ctrl+Alt+Esc เพื่อหยุดงานทันที

## ควบคุมจอ เปิดไฟล์และเกม และซ่อนหน้าติดตามงาน (0.5.4)

- ไม่แสดงหน้าต่างติดตามงานแยกเป็นค่าเริ่มต้น สถานะอยู่ในแชต ต้องการรายละเอียดให้เปิดเมนู **แสดงหน้าต่างติดตามงาน** ก่อนเริ่มงานใหม่ ปุ่มหยุดและ Ctrl+Alt+Esc ยังทำงาน
- **Windows UI Automation**: อ่านชื่อ/ชนิดปุ่มและค่าช่องที่ไม่ใช่รหัสผ่าน ใช้ ValuePattern กรอก/อ่านกลับ และ InvokePattern เรียกปุ่มโดยไม่ขยับเมาส์ ตรวจ handle, process ID/เวลาเริ่ม, ชื่อหน้าต่าง และ runtime ID ของปุ่มก่อนใช้ ข้อมูลเก่ากว่า 30 วินาทีใช้ไม่ได้ การเรียกปุ่มไม่ใช่หลักฐานว่างานเสร็จ ต้องตรวจค่าหรือข้อความตอบรับใหม่
- DOM ของส่วนขยาย Chrome ยังเป็นวิธีหลักสำหรับแท็บที่เชื่อม เพราะอ่านค่าช่อง/ปุ่มของเว็บได้ตรงกว่า UIA หากโปรแกรม/เกมไม่เผยช่องที่เข้าถึงได้ จึงใช้ภาพและคีย์บอร์ด/เมาส์ ขยายปุ่มเดี่ยว A–Z, 0–9 และ F1–F12 แล้ว ไม่รองรับการกดค้างเล่นต่อเนื่องหรือการควบคุมเกมทุกชนิด ไม่ข้ามสิทธิ์ Windows/UAC หรือระบบป้องกันของเกม
- สั่ง **ค้นหาไฟล์รายงานแล้วเปิดให้หน่อย** หรือ **เปิดเกม Limbus Company**: ค้นหาชื่อใน Desktop, Documents, Downloads, Start Menu (ลึกไม่เกิน 4 ชั้น, ไม่เกิน 6,000 รายการ/40 ผลลัพธ์) ไม่สแกนทั้งไดรฟ์ ไม่อ่านเนื้อหา ไม่ตาม symlink และไม่เปิดไฟล์สคริปต์/ตัวติดตั้งโดยตรง เลือกจาก ID ของผลค้นหาที่เพิ่งพบ ตรวจว่าไฟล์ไม่เปลี่ยนก่อนเปิด ทางลัด .lnk/.url เปิดผ่าน Windows และอาจเรียกโปรแกรม/Steam ต้องติดตั้งเกมและมีทางลัดอยู่แล้ว ไม่ถือว่าเกมเปิดสำเร็จจนกว่าจะตรวจหน้าต่าง
- เมนู **โหมดไม่ถาม: จอ/เว็บ/เปิดไฟล์และโปรแกรม (จนปิด Caprii)** เปิดเองครั้งเดียวในรอบนั้นเพื่อใช้ DOM/UIA/คีย์บอร์ด/เมาส์/ค้นหาชื่อและเปิดรายการต่อเนื่อง ไม่บันทึกสิทธิ์ข้ามการเปิดโปรแกรม สคริปต์และการแก้เนื้อหาไฟล์ยังขอแยก ถ้าปิดโหมด/กดหยุดจะหยุดงานปัจจุบัน
- ส่วนขยายแสดงชื่อแท็บที่เลือก และจำรหัสเฉพาะรอบ browser session เพื่อเติมช่องให้อีกครั้งหลังนำทาง ไม่ได้เชื่อมทุกเว็บเอง กดส่วนขยายในแท็บปัจจุบันแล้ว **อนุญาตให้ใช้แท็บนี้** เพื่อเชื่อมใหม่ หากปิดเปิด Caprii ต้องใช้รหัสใหม่ ปุ่มตัดการเชื่อมต่อล้างรหัสที่จำไว้

ทดสอบส่วนขยายบน Google Chrome จริงบน Linux กับฟอร์มท้องถิ่นแล้ว แต่ยังไม่ได้ทดสอบ UI Automation, การเปิดไฟล์/ทางลัดจริง, คีย์เกม หรือ Limbus บน Windows ของผู้ใช้ ภาพหน้าจอที่ส่งมาไม่ได้ให้สิทธิ์เข้าถึงเครื่องของคุณ

## เพิ่มคุณภาพคำตอบและเลือกโมเดล

รุ่น 0.5.4 เปิดโหมด **โฟกัสงาน: ตอบตามข้อเท็จจริงและความยาก** เป็นค่าเริ่มต้น ตอบไทย กระชับเมื่อคำถามง่าย และอธิบายงานยากได้เกิน 3 ประโยค ไม่เพิ่มความจำข้ามงาน ไม่อ้างว่าทำสิ่งที่ยังไม่ได้ทำ ปิดตัวเลือกนี้เพื่อกลับไปใช้บทบาทตัวละครในการสนทนา

คลิกขวา → **โหมดคุณภาพโมเดล** → **สมดุล** (Flash ที่ไม่ใช่ Lite) หรือ **คุณภาพสูง** (Pro ที่มีในรายชื่อ API; หากไม่มีจะเสนอ Flash ที่ไม่ใช่ Lite) ตรวจชื่อโมเดลแล้วเลือก **ทดสอบแล้วใช้** จะส่งคำถามทดสอบสั้นหนึ่งครั้ง และบันทึกเมื่อได้คำตอบไทยเท่านั้น หากยกเลิกไม่ส่งคำขอ หากล้มเหลวเก็บโมเดลเดิม เลือกเฉพาะโมเดล stable ที่ API ของบัญชีส่งกลับมา ไม่สร้างชื่อรุ่นเอง

การทดสอบนี้ยืนยันเพียงว่าโมเดลตอบได้ ไม่ใช่การวัดความแม่นยำ การใช้ API มีโควตา/ราคาแยกจาก Gemini บนเว็บ และไม่ได้ให้เครื่องมือค้นหา/ความสามารถทุกอย่างของเว็บโดยอัตโนมัติ Caprii จึงไม่รับประกันว่าฉลาดเท่ากันทุกงาน ไม่สลับไป Pro เองเมื่อ Lite ไม่ว่าง หรือกลับไป Lite เมื่อ Pro ไม่ว่าง หากโมเดลที่เลือกหายจากรายชื่อ ให้เลือกและทดสอบใหม่ โหมดคุณภาพรอคำตอบแชตได้สูงสุด 60 วินาที โดยยังหยุดได้

## ภาษาไทยและเสียงพูด

บทพูดสำเร็จรูป 477 รายการ เมนูหลัก และคำตอบตั้งเป็นไทย คงเลขอารบิก ชื่อโปรแกรม โค้ด URL และรายละเอียดเทคนิคตามจริง หากโมเดลตอบเป็นอังกฤษล้วน จะขอเรียบเรียงไทยเพิ่มได้หนึ่งครั้ง ภายใต้งบคำขอ/เวลาที่จำกัด ไม่แสดงคำตอบอังกฤษล้วนเป็นคำตอบทั่วไปเมื่อแปลงไม่สำเร็จ

เปิด **อ่านบทพูดด้วยเสียงไทย** จากเมนูได้ ต้องมีเสียงไทยแบบ local ติดตั้งในระบบ หากไม่มีเสียงไทย จะแสดงข้อความไทยแทน ไม่ใช้เสียงอังกฤษหรือบริการอ่านเสียงออนไลน์แทน ปุ่มปิดเสียงยังมีผล

## เชื่อม Chrome เพื่อกรอกช่องโดยตรง

1. คลิกขวา Caprii → **เปิดโฟลเดอร์ส่วนขยาย Chrome**
2. เปิด `chrome://extensions` เปิด Developer mode → Load unpacked → เลือกโฟลเดอร์ที่เปิดในข้อ 1
3. คลิกขวา Caprii → **เชื่อมแท็บ Chrome…** → คัดลอกรหัส
4. เปิดแท็บโจทย์ คลิกส่วนขยาย Caprii วางรหัส → **อนุญาตให้ใช้แท็บนี้**
5. สั่ง **ทำโจทย์บนหน้าเว็บนี้ กรอกคำตอบ แล้วกดส่งให้หน่อย**

ส่วนขยายอ่านช่อง/ปุ่มจาก DOM ของแท็บที่เลือก จึงลดการเดาพิกัดและรองรับการอ่านค่ากลับหลังกรอก หากช่อง read-only จะรายงานให้ใช้แป้นคำตอบบนเว็บ กรอกไม่ติดหรือค่าถูกล้างจะไม่รายงานว่าตรวจผ่าน

รหัสเชื่อมมีอายุเฉพาะรอบที่เปิด Caprii ไม่ใช่คีย์ Gemini ไม่ส่งรหัสในแชต ส่วนขยายไม่ขอสิทธิ์อ่านทุกเว็บไซต์ ข้อมูลแท็บที่เลือกอาจส่งให้ผู้ให้บริการ AI ที่ตั้งไว้ ตัดการเชื่อมต่อจากส่วนขยายได้ หากรีโหลด/เปลี่ยน URL/ปิดแท็บหรือเปิด Caprii ใหม่ ต้องเชื่อมใหม่ เมื่ออัปเดต Caprii ให้ Reload ส่วนขยายใน chrome://extensions ด้วย

ฟังก์ชันนี้ไม่ควบคุมแท็บอื่น หน้า chrome:// หน้าไฟล์ในเครื่อง iframe ข้ามเว็บไซต์ ช่องรหัสผ่าน หรืออัปโหลดไฟล์ ไม่ข้าม CAPTCHA และไม่เปลี่ยนสิทธิ์ผู้ดูแลระบบ

## ดูจอแล้วหาคำตอบ

คำสั่ง “ดูจอแล้วหาคำตอบ” เรียกเครื่องคิดเลข/ตัวแก้ปริศนาแทนการบรรยายภาพอย่างเดียว เป็นคำสั่งหาคำตอบ ไม่กรอกหรือส่งเว้นแต่ขอเพิ่ม เช่น “หาคำตอบแล้วกรอกและกดส่ง”

ภาพจับโดยซ่อนหน้าต่างภายใน Caprii ชั่วคราวแล้วคืนกลับ หากหน้าต่างรหัสเชื่อมต่อเปิดอยู่จะไม่จับภาพ เพื่อไม่ให้ AI อ่านบทพูดเก่าของตัวเอง ไม่ส่งประวัติงานเก่าที่ไม่เกี่ยวข้องไปกับคำถามดูจอแต่ละครั้ง คำตอบทั่วไปและสรุปงานใช้ตัวตรวจภาษาไทย/ถ้อยคำเดียวกัน หากตรวจพบถ้อยคำไม่เหมาะสมจะให้เรียบเรียงใหม่หนึ่งครั้ง ถ้ายังไม่ผ่านจะไม่แสดงข้อความนั้น

## คำสั่งสั้นและการแก้ปัญหา

ใช้ “ทำข้อนี้ให้หน่อย” เพื่ออ่านโจทย์ปัจจุบัน คำนวณ และกรอก ถ้าขอวิธีทำ เช่น “ทำโจทย์ข้อนี้ยังไง” จะอธิบายโดยไม่กรอกหรือส่ง คำสั่ง “ส่งเลย/ส่งให้หน่อย/ทำต่อ” ใช้บริบทคำสั่งในแชตที่เปิดอยู่และอ่านสถานะปัจจุบันใหม่ หากไม่มีบริบทชัดเจนจะถามกลับ ไม่เพิ่ม Memory หรือเก็บคำตอบเดิมข้ามงาน

เมื่อช่อง read-only จะอ่านหน้าใหม่และใช้แป้นบนเว็บได้ การตรวจค่าที่ตรงกับช่องเดิมเท่านั้นจึงยืนยันว่าขั้นตอนที่พิมพ์ไม่สำเร็จได้รับการแก้แล้ว สถานะจะแสดง “กำลังตรวจและแก้” และ “แก้แล้วและตรวจผ่าน” โดยยังเก็บร่องรอยข้อผิดพลาดเดิม

คำสั่งเดิมที่ล้มเหลวจะไม่ถูกส่งซ้ำเกิน 2 ครั้ง หากผลการคลิก/พิมพ์ไม่แน่ชัดหรือแท็บไม่ตอบ จะหยุดส่งคำสั่งเปลี่ยนข้อมูลซ้ำในงานนั้น ให้ตรวจสถานะหรือให้ผู้ใช้ตัดสินใจ ข้อความตอบรับที่มีอยู่ก่อนส่งจะไม่ยืนยันการส่งครั้งใหม่

## พิมพ์คำสั่งด้วยเสียงบน Windows

ในช่องแชตปกติ กดปุ่ม 🎤 แล้วอ่านคำอธิบายและเลือกเริ่ม เลือกภาษาแป้นพิมพ์เป็นไทยก่อน แอปส่งคำขอ Win+H เฉพาะเมื่อช่องแชตของ Caprii อยู่ด้านหน้า ไม่เริ่มจากคำสั่งของโมเดล ไม่ใช้กับช่องคีย์/รหัสผ่าน และไม่เริ่มขณะงาน AI กำลังทำอยู่

Windows เป็นผู้รับและประมวลผลเสียงตามการตั้งค่าระบบ ซึ่งอาจใช้บริการออนไลน์ของ Microsoft แอปไม่บันทึกเสียงเอง เสียงที่รู้จำได้จะลงในช่องแชต **ตรวจข้อความ หยุดไมค์ด้วย Win+H หรือแถบ Windows แล้วกดส่งเอง** ไม่มีการส่งให้ AI อัตโนมัติ

Ctrl+Alt+Esc หยุดงาน AI แต่ไม่ได้ปิดไมค์ของ Windows ฟีเจอร์นี้ต้องอาศัย Windows Voice Typing/ภาษาไทยที่ระบบรองรับ หากปุ่มไม่ทำงาน ให้คลิกช่องแล้วลอง Win+H เอง ปุ่มไม่แสดงบนระบบอื่น การรับเสียงจริงและ shortcut ยังไม่ได้ทดสอบบน Windows ใน cloud นี้

## การทำโจทย์และตรวจผล

ใช้เครื่องคิดเลขจำนวนตรรกยะจริงและตัวแก้ปริศนาตรวจเลข ไม่ใช้คำตอบเดา ปริศนาเลขใช้เลขที่เห็นแต่ละตัวครั้งเดียว รองรับ + − × ÷ วงเล็บ และต่อเลขเฉพาะกติกาที่อนุญาต หากไม่พบคำตอบจะรายงานขอบเขต ไม่แต่งเลขใหม่

คำสั่งกรอก/ส่งต้องมีหลักฐานเรียกเครื่องมือครบ การคำนวณสำเร็จอย่างเดียวไม่ถือว่างานจบ ตรวจค่าช่องหลังกรอก และตรวจข้อความตอบรับหลังส่ง การตรวจชื่อหน้าต่างหรือส่งคลิกได้ไม่ยืนยันว่าเว็บรับคำตอบแล้ว หากติดขัดจะรายงานงานที่ยังไม่ทำ

## การยืนยันและหยุดงาน

ค่าเริ่มต้นถามก่อนทำงาน หากต้องการลดการถาม เปิด **โหมดไม่ถาม: ดูจอ/คลิก/พิมพ์/เปิดเว็บ (จนปิด Caprii)** จากเมนูด้วยตัวเอง สิทธิ์นี้อยู่เฉพาะรอบที่เปิดโปรแกรม ไม่เก็บข้ามครั้ง ไม่เปิดการดูจอเป็นพื้นหลัง ไฟล์/สคริปต์และการเปลี่ยนกติกาโจทย์ยังยืนยันแยก แต่ละงานไม่เกิน 5 นาที หยุดจากหน้าต่างติดตามงานหรือ Ctrl+Alt+Esc ได้

## AI และความจำ

ตั้งผู้ให้บริการและคีย์ผ่านหน้า setup ของแอป ไม่ใส่คีย์ในซอร์สหรือแชต การเก็บคีย์ใช้ secure storage ของระบบหรือ environment binding ที่รองรับ ไม่รับประกันโควตา/ความพร้อมของผู้ให้บริการ โมเดลที่รองรับภาพจำเป็นสำหรับการอ่านจอแบบภาพ แต่ทาง Chrome DOM อ่านข้อความ/ช่องโดยตรงได้

ไม่ได้เพิ่ม Memory ข้ามงาน ประวัติแชตไม่บันทึกข้ามการเปิดโปรแกรมเป็นค่าเริ่มต้น การเชื่อมแท็บและรหัสอยู่ในหน่วยความจำเฉพาะรอบ
