# ติดตั้ง Caprii 0.5.4

1. ปิด Caprii ตัวเก่าจากถาดระบบก่อนติดตั้ง
2. ดาวน์โหลด ZIP ทั้ง repository แล้ว Extract All
3. เข้า downloads/Caprii-0.5.4 แล้วเปิด INSTALL-CAPRII.cmd ไฟล์ part01–03 ต้องอยู่ข้างกัน สคริปต์ตรวจ SHA256 รวมไฟล์ และเปิดตัวติดตั้ง
4. เปิด Caprii Agent ตั้งค่า AI ตามเดิม บทพูดและคำตอบเป็นภาษาไทย ตัวเลือกเสียงไทยอยู่ในเมนู (ต้องมีเสียงไทยแบบ local ใน Windows)

## เพิ่มใน 0.5.4

- Windows UI Automation: อ่านช่อง/ปุ่ม กรอกค่าหรือเรียกปุ่มโดยไม่ขยับเมาส์ ตรวจ process identity และปุ่มเดิมก่อนลงมือ ใช้ภาพ/คีย์บอร์ดเมื่อโปรแกรมหรือเกมไม่เผยโครงสร้าง
- ค้นหาไฟล์/โฟลเดอร์/ทางลัดโปรแกรมใน Desktop, Documents, Downloads และ Start Menu แล้วเปิดเฉพาะผลค้นหาล่าสุด ลองสั่ง เปิดเกม Limbus Company (ต้องติดตั้งและมีทางลัด) ตรวจหน้าต่างหลังเปิด ไม่รับประกันเล่นเกมได้
- หน้าต่างติดตามงานซ่อนเป็นค่าเริ่มต้น เปิดกลับได้ในเมนู แสดงหน้าต่างติดตามงาน สถานะและปุ่มหยุดยังอยู่ในแชต Ctrl+Alt+Esc หยุดงานได้
- โหมดไม่ถามแบบเปิดเองเฉพาะรอบ ครอบคลุมจอ/เว็บ/UIA/ค้นหาและเปิดไฟล์โปรแกรม ไม่บันทึกข้ามเปิดโปรแกรม สคริปต์และการแก้เนื้อหาไฟล์ยังถามแยก
- ส่วนขยายเติมรหัสรอบเดิมให้อีกครั้งหลังนำทาง แสดงชื่อแท็บ กดอนุญาตเชื่อมแท็บปัจจุบันใหม่ รหัสใหม่ยังจำเป็นหลังปิดเปิด Caprii
- ทดสอบส่วนขยายตัวจริงบน Google Chrome 156.0.8078.79/Linux: อ่าน/พิมพ์/อ่านค่ากลับ/คลิก/ตรวจผล และเชื่อมใหม่ผ่าน activeTab สำเร็จ ใช้ฟอร์มท้องถิ่น ไม่ใช่เว็บ Fastmath จริง ส่วน Windows UIA/การเปิดไฟล์จริง/เกม Limbus ยังไม่ได้ทดสอบบน Windows

## ความสามารถที่มีอยู่

- ใช้ “ทำข้อนี้ให้หน่อย”, “ส่งเลย” หรือ “ทำต่อ” ในบริบทแชตที่เปิดอยู่ หากบริบทไม่ชัดจะถามกลับ คำถามขอวิธีทำจะไม่กลายเป็นการกรอก/ส่ง
- แก้การพิมพ์ลงช่อง read-only ด้วยแป้นเว็บ แล้วตรวจค่าช่องเดิมก่อนถือว่าแก้สำเร็จ ไม่ใช้ข้อความตอบรับเก่าเป็นหลักฐานการส่งใหม่
- คำสั่งที่ล้มเหลวจำกัด 2 ครั้ง หากผลไม่แน่ชัดหยุดส่งคำสั่งเปลี่ยนข้อมูลซ้ำ ให้ผู้ใช้ตรวจผล
- ปุ่ม 🎤 ในแชต Windows เปิด Windows Voice Typing แบบกดเริ่มเอง ตรวจข้อความ หยุดไมค์ด้วย Win+H แล้วส่งเอง ไม่มีการส่งให้ AI อัตโนมัติ Windows อาจใช้บริการเสียงออนไลน์ตามการตั้งค่าระบบ การรับเสียงจริงต้องตรวจบน Windows

## ควบคุมช่องและปุ่มใน Chrome โดยตรง

คลิกขวา Caprii → เปิดโฟลเดอร์ส่วนขยาย Chrome แล้ว Load unpacked ใน chrome://extensions จากนั้นเลือกเชื่อมแท็บด้วยรหัสจากเมนู เชื่อมแท็บ Chrome… อ่าน [วิธีเชื่อมแบบละเอียด](CHROME-TH.md)

สั่ง “ทำโจทย์บนหน้าเว็บนี้ กรอกคำตอบ แล้วกดส่งให้หน่อย” ระบบมีเครื่องมืออ่านค่าช่องกลับและตรวจข้อความตอบรับหลังส่ง หากช่อง read-only จะใช้ปุ่มแป้นคำตอบแทนการอ้างว่าพิมพ์แล้ว

อ่าน [คู่มือใช้งาน](GUIDE-TH.md) และ [ผลตรวจ/ข้อจำกัด](VALIDATION.md) ผ่าน 119 การทดสอบและ GUI บน Linux ส่วนการติดตั้งส่วนขยายใน Chrome/Windows และเสียงไทยจริงยังต้องตรวจบนเครื่องคุณ ตัวติดตั้งไม่มีลายเซ็นดิจิทัล
