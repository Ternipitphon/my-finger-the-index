# ติดตั้ง Caprii Agent 0.4.6 บน Windows

1. ดาวน์โหลด repository ทั้งหมดเป็น ZIP: [กดดาวน์โหลด ZIP](https://github.com/Ternipitphon/my-finger-the-index/archive/refs/heads/main.zip)
2. คลิกขวา ZIP แล้วเลือก **Extract All / แตกไฟล์ทั้งหมด** ก่อน อย่าเปิดตัวติดตั้งจากภายใน ZIP
3. เปิดโฟลเดอร์ `downloads/Caprii-0.4.6`
4. ดับเบิลคลิก **INSTALL-CAPRII.cmd** จะตรวจ SHA-256 ของทั้ง 3 ส่วน รวมเป็นตัวติดตั้ง แล้วเปิดตัวติดตั้งให้
5. ตั้งค่า Gemini ตาม [คู่มือภาษาไทย](GUIDE-TH.md)

หาก GitHub ขอให้เข้าสู่ระบบ ให้ใช้บัญชีที่เข้าถึง repository นี้ได้

ไฟล์ `Caprii-Setup.part01`, `.part02`, `.part03` เป็นส่วนของตัวติดตั้ง **ต้องอยู่ด้วยกันทั้งสามไฟล์** ไม่ต้องเปิดทีละส่วน GitHub จำกัดขนาดไฟล์ จึงแบ่งตัวติดตั้งไว้เช่นนี้ สคริปต์ไม่ได้ดาวน์โหลดโปรแกรมอื่นหรือเปลี่ยน execution policy ของ Windows และจะไม่รันไฟล์หาก hash ไม่ตรง

หากไม่ต้องการให้สคริปต์เริ่ม installer อัตโนมัติ สามารถตรวจคำสั่งใน INSTALL-CAPRII.cmd ก่อนใช้งานได้ หลังรวมสำเร็จจะมี `Caprii-Agent-Setup-0.4.6.exe` อยู่ในโฟลเดอร์เดียวกัน

ตัวติดตั้งไม่มีลายเซ็นผู้พัฒนา และยังไม่ได้ทดสอบติดตั้ง/ควบคุม input บน Windows จริง ดู [ผลทดสอบและข้อจำกัด](VALIDATION.md) ก่อนใช้งาน

`Caprii-Agent-0.4.6-source.zip` คือ source พร้อมชุดทดสอบ ไม่จำเป็นต้องแตก source หากใช้ตัวติดตั้ง

## ถ้าขึ้น Cannot find path Caprii-Setup.part01

ไฟล์รวมตัวติดตั้งต้องอยู่กับทั้ง 3 ส่วนในโฟลเดอร์เดียวกัน:

```text
Caprii-0.4.6/
  INSTALL-CAPRII.cmd
  Caprii-Setup.part01   (60 MB)
  Caprii-Setup.part02   (60 MB)
  Caprii-Setup.part03   (ประมาณ 37 MB)
```

หากไม่ครบ ให้ดาวน์โหลด ZIP ทั้ง repository จากลิงก์ด้านบน คลิกขวา ZIP → Extract All / แตกไฟล์ทั้งหมด แล้วเปิด CMD จากโฟลเดอร์ที่แตกแล้ว ไม่ใช่จากหน้าต่าง ZIP และไม่ใช่จาก ZIP source code ที่อยู่ข้างในอีกที

## แก้คำสั่งดูจอภาษาไทย

ปิด Caprii เดิมก่อนติดตั้งรุ่นนี้ หลังติดตั้ง พิมพ์ **ดูจอแล้วพิมพ์คำตอบไป** ได้โดยไม่ต้องใส่ /agent ต้องมีหน้าติดตามงานและคำถามขออนุญาตภาพ/การกระทำปรากฏ หากยังตอบเป็นแชตว่ามองไม่เห็นโดยไม่มีคำถามอนุญาต อาจยังเปิดรุ่นเก่าอยู่

ทดสอบ routing และ Electron แล้ว 40/40 tests ผ่าน แต่ยังต้องยืนยัน Windows native input บนเครื่องจริง
