# ติดตั้ง Caprii 0.5.0

1. ปิด Caprii ตัวเก่าจากถาดระบบก่อนติดตั้ง
2. ดาวน์โหลด ZIP ทั้ง repository แล้ว Extract All
3. เข้า downloads/Caprii-0.5.0 แล้วเปิด INSTALL-CAPRII.cmd ไฟล์ part01–03 ต้องอยู่ข้างกัน สคริปต์ตรวจ SHA256 รวมไฟล์ และเปิดตัวติดตั้ง
4. เปิด Caprii Agent ตั้งค่า AI ตามเดิม บทพูดและคำตอบเป็นภาษาไทย ตัวเลือกเสียงไทยอยู่ในเมนู (ต้องมีเสียงไทยแบบ local ใน Windows)

## ควบคุมช่องและปุ่มใน Chrome โดยตรง

คลิกขวา Caprii → เปิดโฟลเดอร์ส่วนขยาย Chrome แล้ว Load unpacked ใน chrome://extensions จากนั้นเลือกเชื่อมแท็บด้วยรหัสจากเมนู เชื่อมแท็บ Chrome… อ่าน [วิธีเชื่อมแบบละเอียด](CHROME-TH.md)

สั่ง “ทำโจทย์บนหน้าเว็บนี้ กรอกคำตอบ แล้วกดส่งให้หน่อย” ระบบมีเครื่องมืออ่านค่าช่องกลับและตรวจข้อความตอบรับหลังส่ง หากช่อง read-only จะใช้ปุ่มแป้นคำตอบแทนการอ้างว่าพิมพ์แล้ว

อ่าน [คู่มือใช้งาน](GUIDE-TH.md) และ [ผลตรวจ/ข้อจำกัด](VALIDATION.md) ผ่าน 93 การทดสอบและ GUI บน Linux ส่วนการติดตั้งส่วนขยายใน Chrome/Windows และเสียงไทยจริงยังต้องตรวจบนเครื่องคุณ ตัวติดตั้งไม่มีลายเซ็นดิจิทัล
