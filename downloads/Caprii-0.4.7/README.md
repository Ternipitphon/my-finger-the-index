# Caprii 0.4.7 — คำนวณจริง / เมาส์ / YouTube

1. [ดาวน์โหลด ZIP ล่าสุด](https://github.com/Ternipitphon/my-finger-the-index/archive/refs/heads/main.zip) และแตกไฟล์ทั้งหมด
2. ปิด Caprii เดิมให้หมด แล้วเข้า `downloads/Caprii-0.4.7`
3. เปิด **INSTALL-CAPRII.cmd** ไฟล์นี้กับ Caprii-Setup.part01, part02, part03 ต้องอยู่ด้วยกัน จะตรวจ hash รวมตัวติดตั้ง และเริ่มติดตั้ง
4. เปิด Caprii คลิกขวา ตรวจว่าขึ้น **Caprii 0.4.7**
5. เลือก **ทดสอบเมาส์และการพิมพ์** เพื่อดูผลบนเครื่องคุณก่อนสั่งคลิกจริง ผล native test ยังไม่ได้รันใน cloud Linux

ลองคำสั่ง **เปิดyoutube** — จะขออนุญาตแล้วเปิดเบราว์เซอร์โดยตรง ไม่ตอบเพียงว่าจะเปิด

คำสั่ง **คลิกปุ่ม…**, **ใช้เมาส์ลาก…**, **ดับเบิลคลิก…**, **เลื่อนลง**, **พิมพ์…** เข้า Agent ได้โดยไม่ต้องใส่ /agent เลือกโหมด **ทำงานบนจอ/เว็บ** หากไม่ได้แก้โปรเจกต์ ไม่ต้องเลือกโฟลเดอร์

งานเลขมีเครื่องมือตรวจคำนวณจริงและกฎใช้เลขก่อนกรอก รองรับ + − × ÷ วงเล็บ และการต่อเลขเมื่อกฎอนุญาต ไม่รองรับยกกำลัง/แฟกทอเรียลในตัวตรวจเกม หากไม่พบคำตอบภายใต้กฎ จะบอกตามจริง ไม่เติมเลขใหม่เอง

ทดสอบ 59/59 ผ่าน และทดสอบ Gemini เรียก math.solve จริงแล้ว แต่ยังไม่รับรอง native input ทุกโปรแกรมบน Windows ดู [คู่มือ](GUIDE-TH.md) และ [หลักฐาน/ข้อจำกัด](VALIDATION.md) ตัวติดตั้งไม่มีลายเซ็นผู้พัฒนา
