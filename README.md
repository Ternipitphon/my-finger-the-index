# Caprii 0.8.14 — กลับมาใช้ตัวเดิมเป็นฐานหลัก

[ดาวน์โหลดตัวติดตั้ง Windows](https://github.com/Ternipitphon/my-finger-the-index/releases/tag/v0.8.14)

ใช้ Caprii 0.7.6 commit `6899749c0c1e5ad33de58e05cb5420320443962d` เป็นฐาน รักษาหน้าตา ตัวละคร การลาก เสียงไทย การเชื่อม Chrome และเครื่องมือเดิม

เพิ่มความสามารถในการทำงาน: คำสั่งงาน Gemini แบบ JSON ที่ตรวจได้, รอเว็บโหลดแล้วอ่านผลใหม่, กันกดส่งซ้ำขณะยังรอการตอบรับ, หยุดวงจรที่ผลไม่คืบหน้า และกำหนดเวลางานรวม 5 นาที การสนทนาธรรมดาและสิทธิ์เดิมยังคงเดิม

ทดสอบงานคำนวณภาษาไทยกับ Gemini Flash Lite จริงแล้ว โดยไม่ใช้เครื่องมือเว็บ เดสก์ท็อป หรือไฟล์ผู้ใช้ การผ่านทดสอบจำลองไม่ได้ยืนยัน Spotify บัญชีจริงหรือการควบคุมเครื่องทุกสภาพแวดล้อม

ซอร์สอยู่ใน [caprii](caprii) พร้อม Test Lab ที่รันในเครื่อง ไม่มีการเผยแพร่เว็บไซต์ทดสอบในงานนี้ โค้ดเดิมและประกาศลิขสิทธิ์ของ mochiiwuff เก็บไว้ครบตาม [LICENSE](caprii/LICENSE) ส่วนที่เพิ่มเขียนเข้ากับฐานเดิม ไม่ได้นำไฟล์โค้ด GPL ของ CapriCore มารวมไว้
