## Caprii 0.7.0 — ค้นหา YouTube และเล่นเพลง Spotify

ตัวอย่างคำสั่งภาษาพูด:
- `เปิดyoutubeแล้วก็ค้นหาว่าlimbus` เปิด URL หน้าผลค้นหาโดยตรง ไม่ใช้ LLM เดาลิงก์และไม่เปิดคลิปแรกเอง
- `เปิด spotifyแล้วกดเล่นเพลงในliked song` เปิด Liked Songs ในแท็บ Spotify ที่เชื่อม แล้วกดเล่นและตรวจเวลาเพลงเดิน
- `เปิดเพลงชื่อ Harpy Hare ของ Yaelokre ใน Spotify` ค้นหาและเลือกชื่อ/ศิลปินตรงกัน ถ้าชื่อและศิลปินเดียวกันซ้ำหลายชุด ใช้ผลตรงอันดับสูงสุดของ Spotify; ถ้าคนละศิลปินจะถามเพิ่ม
- `เล่นเพลย์ลิสต์ Night Drive` ใช้ลิงก์ในคลังที่อ่านได้; `เล่นเพลงใน playlist นี้` ใช้เพลย์ลิสต์ที่เปิดในแท็บปัจจุบัน ถ้าระบุไม่ได้จะถามชื่อหรือลิงก์
- `เล่นเลย` ทำคำสั่ง Spotify รอบล่าสุดต่อในบทสนทนานี้ได้ ไม่ต้องพิมพ์รายละเอียดซ้ำ หลังเปลี่ยนไปทำงานอื่นจะไม่ย้อนมาเล่นเพลงเก่า

**ตั้งค่า Spotify ครั้งแรก:** ติดตั้ง 0.7.0 แล้วเปิดโฟลเดอร์ส่วนขยายจากเมนู Caprii และรีโหลด/ติดตั้งส่วนขยาย 0.7.0 ใน Chrome เปิด Spotify Web Player ล็อกอินด้วยตัวเอง และอนุญาตให้ Caprii ใช้แท็บนั้น ถ้ายังไม่เชื่อม แอปจะเปิดหน้าที่ต้องการและบอกว่ายังไม่ได้เล่น จากนั้นเชื่อมแท็บแล้วพิมพ์ “เล่นเลย” การค้นหา YouTube ไม่ต้องเชื่อมแท็บ

Spotify ใช้การควบคุม Web Player ไม่ใช้รหัสผ่าน คุกกี้ OAuth token หรือ Spotify API จากบัญชีผู้ใช้ ไม่มีการซื้อ Premium แก้เพลย์ลิสต์ กด Like หรือเปลี่ยนอุปกรณ์เล่นอัตโนมัติ การเล่นยังขึ้นกับสิทธิ์บัญชีและนโยบาย autoplay ของเบราว์เซอร์ อาจต้องกด Play ครั้งแรกในเว็บด้วยตัวเอง หากกดแล้วเวลาไม่เดินจะรายงานว่ายังยืนยันไม่ได้ ไม่มีการกด Play ซ้ำอัตโนมัติ Ctrl+Alt+Esc หยุดขั้นตอนที่เหลือ ส่วนเพลงที่เริ่มแล้วควบคุมจาก Spotify

ส่วนขยายคง session เมื่อย้ายหน้าในเว็บไซต์เดิมที่ผู้ใช้เชื่อม และตัดการเชื่อมต่อเมื่อออกคนละ origin เช่นหน้าเข้าสู่ระบบ ไม่เพิ่มสิทธิ์นอก activeTab/scripting/storage ทดสอบด้วย DOM จำลอง ไม่ใช่บัญชี Spotify หรือเสียงจริง

## Caprii 0.7.0 — ลากได้ช่วงแรกแล้วหยุดทำงาน

เพิ่มการอ่านสถานะปุ่มเมาส์หลักจริงผ่าน Windows helper เดิม (รองรับการสลับปุ่มสำหรับผู้ใช้ถนัดซ้าย) เพื่อใช้ประกอบการจบการลาก ไม่อาศัย pointerup/mouseup เพียงอย่างเดียว ถ้าข้อมูลปุ่มเก่าหรือ helper ไม่พร้อมจะถือว่ายังไม่ทราบสถานะ ไม่ตีความว่าได้ปล่อยปุ่มแล้วโดยอัตโนมัติ

เมื่อจับตัวละครจะยกเลิกเส้นทางเดินเล่นเก่าและเลื่อนการเดินอัตโนมัติออกไป ระหว่างกดค้างจะพักการเดินเล่นก่อนเริ่มลาก ทิ้งตัวอย่างเคอร์เซอร์ที่ตอบช้าจากการจับครั้งก่อน และตรวจการปล่อยปุ่มจริงแม้ไม่มีเหตุการณ์จากหน้าต่าง ทางย้ายสำรอง Ctrl+Alt+M ยังคงใช้ได้ ข้อมูลปุ่มอยู่ในเครื่อง ไม่เก็บลงดิสก์หรือส่งให้ AI

ทดสอบ sprite ลาก–ปล่อย 30 รอบต่อเนื่อง (แอนิเมชันน้อย 15 + เต็ม 15 รอบ) ด้วยสถานะปุ่มจำลอง รวมเหตุการณ์ปล่อยที่มาเร็วและเหตุการณ์ปล่อยที่หายไป ผ่าน 186 app tests แต่ยังไม่ได้ยืนยัน Windows helper และการจับจริงบน Windows

## Caprii 0.7.0 — เปิด Spotify และเว็บอื่นแบบเดียวกับ YouTube

- `เปิด Spotify` / `เปิดสปอติฟาย` / `open Spotify` ส่ง `https://open.spotify.com/` ให้เบราว์เซอร์เริ่มต้นของ Windows โดยตรง ผ่านเส้นทางเดียวกับ YouTube ไม่มีการค้นหาแอปหรือเรียก Agent สำหรับการเปิดเว็บอย่างเดียว

## Caprii 0.7.0 — คลิกติดแต่ลากไม่ขยับ

แก้การลากที่ได้รับ mousemove แต่ไม่มี pointermove รองรับทั้ง MouseEvent และ PointerEvent ไม่ปล่อยตัวละครเพียงเพราะหน้าต่างเสียโฟกัสหรือ mouse pointer capture หลุด และอ่านตำแหน่งเคอร์เซอร์โดยตรงทุกประมาณ 32 ms เฉพาะตอนกำลังจับ ล็อก native click-through ตลอดการจับ ไม่ให้การตรวจ hit/rearm สลับหน้าต่างเป็นคลิกทะลุระหว่างลาก

หากลากโดยตรงยังมีปัญหา: คลิกขวา **ไอคอน Caprii ในถาดระบบข้างนาฬิกา** → **จับย้ายตัวละคร — ขยับเมาส์แล้วคลิกวาง** หรือ **Ctrl+Alt+M** ไม่ต้องกดค้าง คลิกซ้ายเพื่อวางหรือคลิกขวา/Ctrl+Alt+Esc เพื่อยกเลิก เลือกได้เฉพาะหน้าจอที่ตัวละครอยู่ มี timeout 30 วินาทีเพื่อไม่ให้ติดโหมดจับ


## Caprii 0.7.0 — ลากตัวละคร ดูจอ และภาษาอังกฤษ

- ต้องยอมรับการส่งภาพให้ผู้ให้บริการ AI ก่อน ภาพอยู่ในหน่วยความจำชั่วคราว ปิดโหมดแล้วหยุดคำตอบอัตโนมัติที่รออยู่ ไม่ควบคุมเมาส์หรือกรอกฟอร์มเอง
- คลิกขวา → **ภาษา / Language** → **English — primary language** เปลี่ยนภาษาบทสนทนา เมนูที่รองรับ และบทพูดดูจอ บันทึกข้ามการเปิดแอป ค่าเริ่มต้นยังเป็นไทย บางข้อความวินิจฉัยเครื่องมือยังเป็นไทย
- เปิดอ่านบทพูดด้วยเสียงได้ ใช้เสียงระบบที่ตรงกับภาษาหลักเท่านั้น ถ้าไม่มีเสียงภาษานั้นจะไม่อ่านแทนด้วยภาษาอื่น

## ตั้งค่าคำตอบที่ยังคงรองรับ

- **คลิกขวา Caprii → ความยาวคำตอบ / คำพูด** เลือก **สรุปสั้น (1–3 ประโยค)**, **สมดุล**, หรือ **ละเอียด** ค่าเริ่มต้นสรุปสั้นทั้งโปรไฟล์ใหม่และเดิม และจำค่าหลังปิด–เปิดแอป
- ใช้กับแชต การดูหน้าจอ การอ่านรูปแนบ และสรุปตอนจบของ Agent เอาคำตอบหลักขึ้นก่อน ลดคำเกริ่น/มุกซ้ำ ไม่ตัดข้อความกลางประโยคหรือย่อ JSON/โค้ดของเครื่องมือ
- ขอ “อธิบายละเอียดทีละขั้นตอน” หรือ “ขอสั้น ๆ” สำหรับรอบนั้นได้ โดยไม่เปลี่ยนค่าหลัก ความยาวเป็นคำแนะนำให้โมเดล ไม่ใช่การตัดคำตอบด้วยจำนวนตัวอักษรตายตัว
- คำถามอย่าง **“ข้อนี้ตอบอะไร”**, **“อันนี้ตอบอะไร”**, **“ช่วยตอบข้อนี้หน่อย”** จะขออ่านโจทย์จริงจากแท็บที่เชื่อมหรือภาพหน้าจอหลังอนุญาต ตรวจคำตอบด้วยเครื่องมือเมื่อเป็นตัวเลข แล้วตอบโดย **ไม่กรอก/ไม่กดส่ง** ถ้าห้ามอ่านจอจะไม่เริ่มสังเกตจอ
- แก้ข้อความเชื่อม Chrome ให้แยกแอปไม่พร้อม รหัส/รุ่นส่วนขยายไม่ตรง session หมดอายุ และหน้า `file://` ชัดขึ้น พร้อมล้างสถานะเชื่อมต่อหากฉีด DOM script ไม่สำเร็จ
- เพิ่มคำสั่งให้ยึดข้อมูลที่เห็นจริง ไม่เดาตัวเลข ไม่โทษผู้ใช้ และไม่ถามหารูปซ้ำทั้งที่มีภาพแนบจริง ไม่เปลี่ยนโมเดลเป็นรุ่นแพงขึ้นอัตโนมัติ

ทดสอบ Gemini 3.5 Flash Lite ด้วยรูปสังเคราะห์จริง: ตอบจำนวนกล่องสีแดงได้ถูกต้องใน **54 ตัวอักษร** ด้วยค่าเริ่มต้นสรุปสั้น

## บุคลิกและรูปภาพที่ยังคงรองรับ

- **บุคลิกเปิดเป็นค่าเริ่มต้น** ทั้งโปรไฟล์ใหม่และเดิม: พูดตรง มั่นใจ ขี้แซวแบบเป็นมิตรและห่วงผู้ใช้ ได้แรงบันดาลใจจากรีเบคก้า ปิดได้ที่เมนู “บุคลิกกวน ๆ แบบรีเบคก้า” ไม่ใช่ตัวละครจริงหรือผลงานทางการ บุคลิกไม่แทนที่ข้อเท็จจริงหรือการอนุญาตเครื่องมือ
- **ปุ่ม 📎 แนบรูปในแชต** เลือก PNG/JPEG/WebP หรือคัดลอกรูปแล้ววางด้วย **Ctrl+V** มีตัวอย่างก่อนส่ง ลบรูปออกได้ ใส่คำถามหรือส่งเฉพาะรูปก็ได้
- วิเคราะห์รูปที่แนบจริง **แยกจากการดูหน้าจอ** ส่งพิกเซลให้ provider/model ที่เลือกเมื่อกดส่ง ไม่บันทึกพิกเซลลงประวัติแชต ไฟล์ไม่เกิน 15 MB / 40 ล้านพิกเซล และย่อด้านยาวไม่เกิน 1600 px
- โมเดลที่ไม่รองรับภาพจะแจ้งและเก็บรูปให้เปลี่ยนโมเดล/ลองใหม่ ไม่แอบเปลี่ยนเป็นคำตอบข้อความล้วน ช่องนี้ยังไม่รองรับ Claude Code mode ใช้ Gemini หรือโมเดล vision ที่รองรับแทน
- ทดสอบ Gemini 3.5 Flash Lite ด้วย PNG สังเคราะห์จริงแล้ว นับกล่องสีแดง 3 กล่องได้ถูกต้อง โดยเปิดบุคลิกใหม่ ไม่ได้ใช้รูปส่วนตัว
- Test Lab เพิ่มเคสอ่านรหัสจากภาพเป็น **8 เคส** เว็บตรวจรหัสที่กรอก ไม่ให้คะแนนบุคลิกหรือยืนยันด้วยตัวเองว่า AI เป็นผู้ลงมือ

ตัวอย่าง: แนบรูปแล้วบอก “ดูรูปที่ส่งให้หน่อย รหัสบนภาพเขียนว่าอะไร อย่าไปดูจอแทนนะ”

## เปิดเว็บทดสอบ Caprii

**คลิกขวาตัวละคร → เปิดเว็บทดสอบ Caprii**

แอปจะเปิด server เฉพาะในเครื่องและเปิดหน้า Test Lab ใน browser ให้เอง ใช้ URL ที่แอปเปิดให้จริง พอร์ตอาจต่างจาก `5173` เมื่อปิด Caprii เว็บในเครื่องจะหยุดทำงาน

เลือกเคส → เชื่อมแท็บนั้นผ่านส่วนขยาย Caprii → คัดลอกคำสั่งไปบอก Caprii → ดูฟอร์มและ “หลักฐานของรอบนี้”

มี 8 เคส: อ่านข้อมูล, กรอกฟอร์ม, คำนวณ, ใช้แป้นบนช่อง readonly, รอผลช้าโดยไม่กดซ้ำ, อ่านช่องใหม่หลัง element เปลี่ยน กรอกโดยห้ามส่ง และอ่านรหัสจากรูปที่นำไปแนบในแชต ส่งออกรายงาน JSON เพื่อเก็บผลเทียบเวอร์ชันได้

ผลผ่านมาจากค่าช่องและเหตุการณ์บนหน้า เว็บยังแยกไม่ได้ว่าผู้ใช้หรือ Caprii เป็นผู้ลงมือ และไม่ยืนยันการบันทึกข้อมูลบน server ไม่มีการ publish เว็บทดสอบออนไลน์

ซอร์สเว็บและแนวทางอัปเดตพร้อม Caprii อยู่ที่ [Test Lab](https://github.com/Ternipitphon/my-finger-the-index/tree/caprii-0.7.0/caprii/test-lab)

## ความสามารถเดิมที่ยังอยู่

รวม Agent Reach 1.6.0 แบบ public-only พร้อม Python/dependencies ที่ล็อกเวอร์ชันและตรวจ checksum ใน Windows installer วางลิงก์เพื่ออ่านเว็บ ข้อมูลหรือคำบรรยาย YouTube และค้นข้อมูลผ่าน Jina/Exa/yt-dlp ไม่คัดลอกบัญชีหรือคุกกี้ ไม่ถอดเสียงแบบมีค่าใช้จ่าย ไม่อ้างว่าได้ดูคลิปจาก metadata และไม่ข้ามการปิดกั้นเครือข่าย

ยังมี Windows UI Automation, เครื่องมือเปิดไฟล์/โปรแกรม, การคำนวณพร้อมตรวจคำตอบ และการซ่อนหน้าติดตามงานตามการตั้งค่าเดิม ไม่เพิ่มความจำข้ามงานจากการอัปเดตนี้

## ทดสอบอะไรแล้ว

Chromium ใน environment ทดสอบนี้ถูกนโยบายผู้ดูแลบล็อกการโหลด unpacked extension จึงยังไม่ผ่านการทดสอบ popup/worker จริงใน Chromium ของรอบนี้ ใช้ unit tests และ authenticated broker/isolated DOM smoke ตรวจส่วนที่ทำได้ โดยไม่เปลี่ยนนโยบายหรืออ้างว่าเป็นผลบน Chrome/Windows จริง


ทดสอบหน้าต่าง Chat/Panel จริงเพิ่มเติม: แนบรูป, preview ก่อนส่ง, HTTP payload แบบหลายสื่อ, Ctrl+V ผ่าน ClipboardItem API, ส่งเฉพาะรูป, ถอดรูป, และแจ้งเมื่อโมเดลไม่รองรับภาพ รวมทั้งตรวจว่า history ไม่มีพิกเซลรูป


- **202 application tests ผ่าน** รวมวงจรเปิด/ปิด server ของ Test Lab และการตรวจเวอร์ชันแอป/lock/ส่วนขยายให้ตรงกัน
- **3 Test Lab unit/server checks ผ่าน**
- **8 เคส browser จริงผ่าน** พร้อมกรณีตอบผิด, readonly keypad, ผลตอบกลับช้า/รีเซ็ต, element เก่า, ห้ามส่ง, ตัวกรอง, รายงาน JSON และขนาดหน้าจอมือถือ
- ตรวจแพ็กเกจจริง: ASAR เวอร์ชัน 0.7.0, Windows x64 PE, Python ที่รวมไว้, ฟอนต์, ส่วนขยาย/DOM bridge และเปิด Test Lab จาก ASAR ได้
- ตรวจ archive ของ NSIS ผ่าน และรวม part กลับมาได้ SHA256 ตรงกับ installer

**ยังไม่ได้ลองติดตั้งและควบคุมบน Windows จริง** การ cross-build และการทดสอบบน Linux ไม่ยืนยันว่าการควบคุม Windows หรือทุกเว็บไซต์จะทำงานครบ ตัวติดตั้งยังไม่มีลายเซ็นดิจิทัล การอ่านเว็บจริงขึ้นกับเครือข่าย โควตา และข้อมูลที่เว็บไซต์เปิดให้ใช้
