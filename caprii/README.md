## Caprii 0.7.1 — เชื่อมแล้วแต่แอปยังบอกว่าไม่ได้เชื่อม

แก้สถานะไม่ตรงกัน: รุ่นก่อน popup จำว่าเชื่อมไว้ แต่แอปถือว่าหลุดเมื่อ heartbeat เกิน 8 วินาที และตัวส่งคำสั่งในหน้าเว็บหยุดเมื่อเจอข้อผิดพลาดชั่วคราว รุ่นนี้เก็บสิทธิ์การเชื่อมจนตัดจริง แยกสถานะยังรอสัญญาณออกจากยังไม่ได้อนุญาต และ popup ติดต่อแอปจริงก่อนแสดงว่าเชื่อมอยู่

ส่งคำสั่งผ่าน extension worker แทน page timers ที่อาจถูก Chrome ชะลอในแท็บเบื้องหลัง โหลด DOM bridge เมื่อจำเป็นและคืนการทำงานหลังเครือข่ายสะดุด ไม่ส่งคำสั่งที่รับไปทำแล้วซ้ำเมื่อ ack หาย ยังควบคุมเฉพาะแท็บและ origin ที่ผู้ใช้เลือก ไม่เพิ่มสิทธิ์ส่วนขยาย

**อัปเดตทั้งแอปและส่วนขยายเป็น 0.7.1:** ปิด Caprii จากถาดระบบก่อนติดตั้ง เปิดโฟลเดอร์ส่วนขยายจากแอปใหม่และกด Reload ใน chrome://extensions จากนั้นเปิดแท็บ Spotify ที่ล็อกอินแล้ว เชื่อมใหม่ด้วยรหัสของรอบนี้ครั้งเดียว แล้วพิมพ์ “เล่นเลย” การพักแท็บอย่างเดียวไม่ต้องกดเชื่อมใหม่ทุกคำสั่ง

เมื่ออยู่หน้า Liked Songs ที่ต้องการอยู่แล้วจะไม่โหลดหน้าใหม่ และการกด Play ไม่รอตัวจับเวลาในหน้าเว็บ การเปิดหน้าตัวเล่นเป็นคนละขั้นกับการยืนยันเพลงเล่น จึงยังตรวจสถานะและเวลาเดินตามเดิม หากเชื่อมผิดแท็บจะบอกชื่อเว็บไซต์ที่เชื่อมอยู่ ถ้ารุ่นส่วนขยายไม่ตรงจะแจ้งให้อัปเดตตรงจุด

## Caprii 0.7.1 — ค้นหา YouTube และเล่นเพลง Spotify

ตัวอย่างคำสั่งภาษาพูด:
- `เปิดyoutubeแล้วก็ค้นหาว่าlimbus` เปิด URL หน้าผลค้นหาโดยตรง ไม่ใช้ LLM เดาลิงก์และไม่เปิดคลิปแรกเอง
- `เปิด spotifyแล้วกดเล่นเพลงในliked song` เปิด Liked Songs ในแท็บ Spotify ที่เชื่อม แล้วกดเล่นและตรวจเวลาเพลงเดิน
- `เปิดเพลงชื่อ Harpy Hare ของ Yaelokre ใน Spotify` ค้นหาและเลือกชื่อ/ศิลปินตรงกัน ถ้าชื่อและศิลปินเดียวกันซ้ำหลายชุด ใช้ผลตรงอันดับสูงสุดของ Spotify; ถ้าคนละศิลปินจะถามเพิ่ม
- `เล่นเพลย์ลิสต์ Night Drive` ใช้ลิงก์ในคลังที่อ่านได้; `เล่นเพลงใน playlist นี้` ใช้เพลย์ลิสต์ที่เปิดในแท็บปัจจุบัน ถ้าระบุไม่ได้จะถามชื่อหรือลิงก์
- `เล่นเลย` ทำคำสั่ง Spotify รอบล่าสุดต่อในบทสนทนานี้ได้ ไม่ต้องพิมพ์รายละเอียดซ้ำ หลังเปลี่ยนไปทำงานอื่นจะไม่ย้อนมาเล่นเพลงเก่า

**ตั้งค่า Spotify ครั้งแรก:** ติดตั้ง 0.7.1 แล้วเปิดโฟลเดอร์ส่วนขยายจากเมนู Caprii และรีโหลด/ติดตั้งส่วนขยาย 0.7.1 ใน Chrome เปิด Spotify Web Player ล็อกอินด้วยตัวเอง และอนุญาตให้ Caprii ใช้แท็บนั้น ถ้ายังไม่เชื่อม แอปจะเปิดหน้าที่ต้องการและบอกว่ายังไม่ได้เล่น จากนั้นเชื่อมแท็บแล้วพิมพ์ “เล่นเลย” การค้นหา YouTube ไม่ต้องเชื่อมแท็บ

Spotify ใช้การควบคุม Web Player ไม่ใช้รหัสผ่าน คุกกี้ OAuth token หรือ Spotify API จากบัญชีผู้ใช้ ไม่มีการซื้อ Premium แก้เพลย์ลิสต์ กด Like หรือเปลี่ยนอุปกรณ์เล่นอัตโนมัติ การเล่นยังขึ้นกับสิทธิ์บัญชีและนโยบาย autoplay ของเบราว์เซอร์ อาจต้องกด Play ครั้งแรกในเว็บด้วยตัวเอง หากกดแล้วเวลาไม่เดินจะรายงานว่ายังยืนยันไม่ได้ ไม่มีการกด Play ซ้ำอัตโนมัติ Ctrl+Alt+Esc หยุดขั้นตอนที่เหลือ ส่วนเพลงที่เริ่มแล้วควบคุมจาก Spotify

ส่วนขยายคง session เมื่อย้ายหน้าในเว็บไซต์เดิมที่ผู้ใช้เชื่อม และตัดการเชื่อมต่อเมื่อออกคนละ origin เช่นหน้าเข้าสู่ระบบ ไม่เพิ่มสิทธิ์นอก activeTab/scripting/storage ทดสอบด้วย DOM จำลอง ไม่ใช่บัญชี Spotify หรือเสียงจริง

## Caprii 0.7.1 — ลากได้ช่วงแรกแล้วหยุดทำงาน

เพิ่มการอ่านสถานะปุ่มเมาส์หลักจริงผ่าน Windows helper เดิม (รองรับการสลับปุ่มสำหรับผู้ใช้ถนัดซ้าย) เพื่อใช้ประกอบการจบการลาก ไม่อาศัย pointerup/mouseup เพียงอย่างเดียว ถ้าข้อมูลปุ่มเก่าหรือ helper ไม่พร้อมจะถือว่ายังไม่ทราบสถานะ ไม่ตีความว่าได้ปล่อยปุ่มแล้วโดยอัตโนมัติ

เมื่อจับตัวละครจะยกเลิกเส้นทางเดินเล่นเก่าและเลื่อนการเดินอัตโนมัติออกไป ระหว่างกดค้างจะพักการเดินเล่นก่อนเริ่มลาก ทิ้งตัวอย่างเคอร์เซอร์ที่ตอบช้าจากการจับครั้งก่อน และตรวจการปล่อยปุ่มจริงแม้ไม่มีเหตุการณ์จากหน้าต่าง ทางย้ายสำรอง Ctrl+Alt+M ยังคงใช้ได้ ข้อมูลปุ่มอยู่ในเครื่อง ไม่เก็บลงดิสก์หรือส่งให้ AI

ทดสอบ sprite ลาก–ปล่อย 30 รอบต่อเนื่อง (แอนิเมชันน้อย 15 + เต็ม 15 รอบ) ด้วยสถานะปุ่มจำลอง รวมเหตุการณ์ปล่อยที่มาเร็วและเหตุการณ์ปล่อยที่หายไป ผ่าน 186 app tests แต่ยังไม่ได้ยืนยัน Windows helper และการจับจริงบน Windows

## Caprii 0.7.1 — คลิกติดแต่ลากไม่ขยับ

แก้การลากที่ได้รับ mousemove แต่ไม่มี pointermove รองรับทั้ง MouseEvent และ PointerEvent ไม่ปล่อยตัวละครเพียงเพราะหน้าต่างเสียโฟกัสหรือ mouse pointer capture หลุด และอ่านตำแหน่งเคอร์เซอร์โดยตรงทุกประมาณ 32 ms เฉพาะตอนกำลังจับ ล็อก native click-through ตลอดการจับ ไม่ให้การตรวจ hit/rearm สลับหน้าต่างเป็นคลิกทะลุระหว่างลาก

หากลากโดยตรงยังมีปัญหา: คลิกขวา **ไอคอน Caprii ในถาดระบบข้างนาฬิกา** → **จับย้ายตัวละคร — ขยับเมาส์แล้วคลิกวาง** หรือ **Ctrl+Alt+M** ไม่ต้องกดค้าง คลิกซ้ายเพื่อวางหรือคลิกขวา/Ctrl+Alt+Esc เพื่อยกเลิก เลือกได้เฉพาะหน้าจอที่ตัวละครอยู่ มี timeout 30 วินาทีเพื่อไม่ให้ติดโหมดจับ

ใช้ Node.js 24 และ `npm ci` จากโฟลเดอร์นี้ รัน `npm test` สำหรับชุดทดสอบ หากมี X11/หน้าจอจริง รัน `npm run test:electron`, `npm run test:chrome-ui`, `npm run test:site-ui` สำหรับฟอร์ม/การเชื่อมต่อ/แอปจริง `npm run test:windows` ต้องรันใน Windows ที่เปิดหน้าจออยู่

สร้าง Windows x64 ด้วย `npm run dist:cloud` ใน cloud ใช้ `NODE_USE_ENV_PROXY=1` และรักษาการตรวจ TLS/ลายเซ็น/เช็กซัมตามระบบ ไม่ถือว่าการสร้างบน Linux ยืนยันการติดตั้งหรือการควบคุม Windows จริง

ซอร์สส่วนขยายอยู่ที่ `browser-extension/` และใช้ DOM bridge เดียวกับเบราว์เซอร์ Electron ใน `src/shared/browser-dom.js` หากเปลี่ยน bridge ให้คัดลอกไป `browser-extension/dom.js` ด้วย ชุดทดสอบตรวจว่าไฟล์ตรงกัน รักษา public key ใน manifest และ ID ที่ตรึงไว้ให้ตรงกัน ไม่สร้าง ID ใหม่ทุกครั้งที่ build

Chrome broker ฟังเฉพาะ loopback หลังผู้ใช้เลือกเชื่อม รหัสเกิดใหม่ทุกครั้งที่เปิดโปรแกรม ไม่บันทึกคีย์ลงไฟล์หรือ log คำสั่งรองรับเฉพาะอ่าน/กรอก/คลิก/ตรวจค่า ไม่มีเครื่องมือ eval หรือ shell ผ่านส่วนขยาย

## Caprii Test Lab

Run `npm run lab`, open `http://127.0.0.1:5173` in Chrome, connect that tab to Caprii, and copy a test prompt. See [test-lab/README-TH.md](test-lab/README-TH.md) for seven versioned regression cases and JSON evidence reports. Installed users can choose เปิดเว็บทดสอบ Caprii from the tray menu without installing Node.js. The lab runs locally and is updated alongside capability changes.
