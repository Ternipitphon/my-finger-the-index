## Caprii 0.7.6 — Spotify เปิดใหม่และเล่นอัตโนมัติ

แก้ช่วงรอแท็บใหม่ไม่ให้ติดล็อกว่างานกำลังทำอยู่ รอเอกสาร Spotify โหลดครบและใช้ session ใหม่ก่อนเล่น ไม่ส่งคำสั่งอัตโนมัติไปแท็บเก่าที่ไม่ได้ใช้งาน รองรับลิงก์ /intl-th/ และ /intl-en/ อ่านปุ่มและเอกสารใหม่ทุกครั้ง

เมนูคลิกขวา → **เล่นเพลงอัตโนมัติเมื่อเปิด Spotify** เปิดเป็นค่าเริ่มต้นตามคำขอผู้ใช้ เมื่อสั่ง “เปิด Spotify” จะเล่นเพลงล่าสุดที่เคยตรวจได้ มีสวิตช์ปิดเป็นเปิดเว็บอย่างเดียว บันทึกเฉพาะชื่อ ศิลปิน และ public track URL ในเครื่อง ถ้ายังไม่มีเพลงล่าสุดในเว็บ/แอป ให้สั่งชื่อเพลงหรือ Liked Songs ครั้งแรกก่อน ไม่เลือกเพลงสุ่มแทน

หลังเปิด Spotify สั่ง “หยุดเพลง”, “ข้ามเพลง”, “เพลงก่อนหน้า” และ “เล่นต่อ” ได้ผ่านปุ่ม Spotify โดยตรง ตรวจว่าเวลาหยุดหรือเพลงเปลี่ยนแล้ว ไม่รายงานจากการกดปุ่มอย่างเดียว

แยกเวลาเพลงเดินกับ Chrome รายงานเสียง ตรวจแท็บปิดเสียง อุปกรณ์ที่กำลังเล่น และเอกสารที่เปลี่ยน ถ้าสถานะที่กู้คืนบอกว่าเล่นอยู่แต่ไม่มีเสียง จะลองเปิดเพลงเดิมใหม่หนึ่งครั้ง ไม่วนกด หากพบอุปกรณ์อื่นจะเลือกเฉพาะตัวเลือก This web browser ที่ระบุชัด ถ้าระบุไม่ได้จะแจ้งให้เลือกเอง ไม่เปลี่ยนไปอุปกรณ์อื่น การรายงานเสียงของ Chrome ยังไม่ยืนยันเสียงลำโพงหรือ Volume Mixer และ Chrome อาจต้องให้กด Play เองครั้งแรก

**อัปเดตทั้งแอปและส่วนขยาย 0.7.6:** ปิดแอปเก่าจากถาดระบบ ติดตั้งใหม่ แล้วกด Reload ส่วนขยายใน chrome://extensions เชื่อมใหม่ด้วยรหัสรอบนี้และเปิดโหมดจำ Chrome หากต้องการปิดแท็บแล้วเปิดใหม่โดยไม่ใส่รหัสซ้ำ

## Caprii 0.7.5 — ปุ่มคุยอยู่นิ่ง ไม่ตอบสนอง

เพิ่มทางสำรองเฉพาะปุ่ม “คุยกับฉัน” ตอนว่าง โดยอ่านขอบการกด–ปล่อยปุ่มเมาส์หลักจาก Windows helper เดิม แม้ไม่มี DOM mouse events ก็เรียกเปิดแชตได้ ต้องกดและปล่อยบนปุ่มเดิม ไม่กดติดจากการลากผ่าน ไม่ทำงานแทนปุ่มอนุญาต/ส่งข้อมูล และกันการเปิดซ้ำจาก native + DOM หรือคลิกที่มาช้าบนปุ่มเก่า

ส่วนขยายคง session เมื่อย้ายหน้าในเว็บไซต์เดิมที่ผู้ใช้เชื่อม และตัดการเชื่อมต่อเมื่อออกคนละ origin เช่นหน้าเข้าสู่ระบบ ไม่เพิ่มสิทธิ์นอก activeTab/scripting/storage ทดสอบด้วย DOM จำลอง ไม่ใช่บัญชี Spotify หรือเสียงจริง

แก้การลากที่ได้รับ mousemove แต่ไม่มี pointermove รองรับทั้ง MouseEvent และ PointerEvent ไม่ปล่อยตัวละครเพียงเพราะหน้าต่างเสียโฟกัสหรือ mouse pointer capture หลุด และอ่านตำแหน่งเคอร์เซอร์โดยตรงทุกประมาณ 32 ms เฉพาะตอนกำลังจับ ล็อก native click-through ตลอดการจับ ไม่ให้การตรวจ hit/rearm สลับหน้าต่างเป็นคลิกทะลุระหว่างลาก

หากลากโดยตรงยังมีปัญหา: คลิกขวา **ไอคอน Caprii ในถาดระบบข้างนาฬิกา** → **จับย้ายตัวละคร — ขยับเมาส์แล้วคลิกวาง** หรือ **Ctrl+Alt+M** ไม่ต้องกดค้าง คลิกซ้ายเพื่อวางหรือคลิกขวา/Ctrl+Alt+Esc เพื่อยกเลิก เลือกได้เฉพาะหน้าจอที่ตัวละครอยู่ มี timeout 30 วินาทีเพื่อไม่ให้ติดโหมดจับ

ผู้ช่วยบนเดสก์ท็อปที่คุยภาษาไทย อ่านจอ ทำโจทย์ และใช้เครื่องมือโดยตรวจผลจริง

- แก้ช่อง read-only ผ่านแป้นเว็บ พร้อมหลักฐานค่าช่องเดิม และหยุดการลองซ้ำเมื่อผลไม่แน่ชัด
- ปุ่มพิมพ์คำสั่งด้วยเสียงผ่าน Windows Voice Typing แบบเลือกเริ่มเอง ตรวจข้อความก่อนส่ง (ต้องตรวจบน Windows จริง)
- บทพูดไทย 477 รายการ และการกำกับคำตอบให้เป็นไทยโดยคงโค้ด/เลข/ชื่อโปรแกรมตามจริง
- ตัวเลือกอ่านออกเสียงด้วยเสียงไทยแบบ local ไม่ใช้เสียงอังกฤษหรือส่งไปบริการอ่านเสียงอื่นแทน
- ส่วนขยาย Chrome แบบเลือกแท็บเอง เชื่อมด้วยรหัสที่หมดอายุเมื่อปิดแอป ไม่ขอสิทธิ์อ่านทุกเว็บไซต์
- กรอกช่องแล้วอ่านค่ากลับ รองรับแป้นบนเว็บเมื่อช่อง read-only และตรวจผลหลังส่งแยกจากการพิมพ์
- คิดเลขด้วยเครื่องมือจริง ปฏิเสธคำตอบเดา และไม่ถือว่าคำนวณได้เท่ากับกรอก/ส่งแล้ว
- โหมดไม่ถามแบบเลือกเปิดเองต่อรอบ ปุ่มหยุดและ Ctrl+Alt+Esc ยังทำงาน ไม่เพิ่ม Memory ข้ามงาน

## พัฒนา

ใช้ Node.js 24 และ `npm ci` จากโฟลเดอร์นี้ รัน `npm test` สำหรับชุดทดสอบ หากมี X11/หน้าจอจริง รัน `npm run test:electron`, `npm run test:chrome-ui`, `npm run test:site-ui` สำหรับฟอร์ม/การเชื่อมต่อ/แอปจริง `npm run test:windows` ต้องรันใน Windows ที่เปิดหน้าจออยู่

สร้าง Windows x64 ด้วย `npm run dist:cloud` ใน cloud ใช้ `NODE_USE_ENV_PROXY=1` และรักษาการตรวจ TLS/ลายเซ็น/เช็กซัมตามระบบ ไม่ถือว่าการสร้างบน Linux ยืนยันการติดตั้งหรือการควบคุม Windows จริง

ซอร์สส่วนขยายอยู่ที่ `browser-extension/` และใช้ DOM bridge เดียวกับเบราว์เซอร์ Electron ใน `src/shared/browser-dom.js` หากเปลี่ยน bridge ให้คัดลอกไป `browser-extension/dom.js` ด้วย ชุดทดสอบตรวจว่าไฟล์ตรงกัน รักษา public key ใน manifest และ ID ที่ตรึงไว้ให้ตรงกัน ไม่สร้าง ID ใหม่ทุกครั้งที่ build

Chrome broker ฟังเฉพาะ loopback หลังผู้ใช้เลือกเชื่อม รหัสเกิดใหม่ทุกครั้งที่เปิดโปรแกรม ไม่บันทึกคีย์ลงไฟล์หรือ log คำสั่งรองรับเฉพาะอ่าน/กรอก/คลิก/ตรวจค่า ไม่มีเครื่องมือ eval หรือ shell ผ่านส่วนขยาย

## Caprii Test Lab

Run `npm run lab`, open `http://127.0.0.1:5173` in Chrome, connect that tab to Caprii, and copy a test prompt. See [test-lab/README-TH.md](test-lab/README-TH.md) for seven versioned regression cases and JSON evidence reports. Installed users can choose เปิดเว็บทดสอบ Caprii from the tray menu without installing Node.js. The lab runs locally and is updated alongside capability changes.
