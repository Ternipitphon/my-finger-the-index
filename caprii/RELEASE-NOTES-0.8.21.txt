# Caprii 0.8.21 / Test Lab 1.29.0 — Spotify ชื่อยาวและปุ่มภาษาไทย

แก้กรณีภาพ I Really Want to Stay at Your House: รองรับป้าย เล่นเพลง/เล่น/Play บนปุ่มการ์ดซ้อนหลายชั้นและปุ่ม MSAA LegacyIAccessible ที่มี role ปุ่มและ default action ชัดเจน เลือกวิธีเดียว ตรวจ method/label/ผล/ลำดับ/อายุหน้าต่างก่อนกดหนึ่งครั้ง ไม่ fallback เป็น Space หรือคลิกพิกัด

หากช่องค้นหามี plus/percent encoding ของคำค้นนี้พอดี จะอ่าน runtime id และค่าก่อนแก้ช่อง Edit ที่เขียนได้ใน Spotify เป็นข้อความมีช่องว่างเพียงครั้งเดียว ตรวจอายุหน้าต่างและ readback ก่อนอ่านผลใหม่ ไม่แก้ช่องค้นหาอื่นหรือกรอกซ้ำเมื่อผลไม่ชัด

ชื่อเพลงเทียบ NFKC ตัวพิมพ์ ช่องว่างและอัญประกาศ โดยไม่ตัด suffix เวอร์ชัน Instrumental/1 HOUR รองรับศิลปินหลายคนใน metadata แต่ต้องตรงข้อมูลบนผลที่เลือก ไม่ใช้เพลง Magnolia หรือศิลปินอื่นที่เล่นอยู่เป็นหลักฐานสำเร็จ ยืนยัน Playing สองครั้ง ยังไม่อ้างเสียงลำโพง

เพิ่ม UI Automation บน Windows กับหน้าจำลองชื่อเพลงยาว ศิลปิน Rosa Walton/Hallie Coggins ปุ่มไทย การ์ดซ้อนชั้น ช่อง plus-query และ footer Magnolia ไม่ใช่บัญชี Spotify จริง หน้า Lab ไม่วัดคะแนนการเล่นเพลงจริง อนิเมชัน/สวิตช์และวิธีดูจอ 0.8.20 คงเดิม
