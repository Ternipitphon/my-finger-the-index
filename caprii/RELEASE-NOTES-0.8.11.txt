Caprii 0.8.11

AI เลือกตอบหรือเรียกเครื่องมือในรอบเดียว แชตทั่วไปได้คำตอบทันทีจากรอบตัดสินใจโดยไม่เรียก AI ตอบซ้ำ รักษาบริบท นิสัย ภาษาและความยาวคำตอบ สั่งงานแล้วใช้เครื่องมือจริงพร้อมตรวจผล ดูจออย่างเดียวใช้ภาพจริงตามสิทธิ์เดิม

งานหลายขั้นตอน การดูภาพ โมเดลสำรอง หรือการแก้ถ้อยคำยังอาจต้องเรียก AI เพิ่มตามความจำเป็น ไม่เปลี่ยนสิทธิ์อัตโนมัติของงานอื่น โหมด Claude Code ยังใช้ Agent เดิม

ตรวจ unit, native Windows chat/menu/browser/player/transport และ Test Lab ก่อนสร้างตัวติดตั้ง ไม่ได้ทดสอบเสียงจากบัญชี Spotify จริง
