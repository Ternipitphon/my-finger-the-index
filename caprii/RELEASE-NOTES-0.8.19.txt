# Caprii 0.8.19 / Test Lab 1.27.0 — อ่านปุ่ม Play บนการ์ดผลค้นหา

แก้รูปแบบในภาพที่ปุ่ม Play อยู่การ์ดผลบนสุด แยกจาก DataItem แถวรายการเพลง อ่านปุ่มจาก ancestor ขนาดเล็กที่มีชื่อเพลงตรง ตัดบริเวณ footer ที่มีปุ่ม next/previous หรือ slider ออก เรียงการ์ดและแถวตามตำแหน่งบนจอ ตรวจเป้าหมาย ลำดับ และอายุหน้าต่างก่อน Invoke ครั้งเดียว ไม่ใช้พิกัดคลิกหรือ Space

ก่อนกด ตรวจ Windows media session ชื่อเพลงและศิลปินของผลที่เลือก ถ้า Playing ตรงสองครั้งให้รายงานสำเร็จโดยไม่กด แม้แถวนั้นไม่มีปุ่ม Play ข้อความ Song • / เพลง • ชื่อศิลปินรองรับด้วย หากเพลงอื่นเล่นอยู่หรือเพลงที่ขอหยุดอยู่ ไม่ใช้เป็นหลักฐานสำเร็จ

เพิ่ม Windows UI Automation จริงกับหน้า Electron จำลองแบบภาพ: การ์ด Play, แถวไม่มีปุ่ม, footer Play, ป้องกันผลเปลี่ยนและ guard ปฏิเสธ ต้องไม่กด footer หรือกดซ้ำ นี่ไม่ใช่การทดสอบบัญชี Spotify จริง การค้นในแอปยังทดลองตาม Spotify รุ่นที่ใช้ ยังไม่ยืนยันเสียงลำโพง หน้าเว็บ Test Lab ไม่วัดผล Spotify จริง เล่นต่อ/หยุด/ข้ามเดิมคงอยู่
