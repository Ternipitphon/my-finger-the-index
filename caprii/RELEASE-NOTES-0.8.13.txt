Caprii 0.8.13

จำการจับคู่ Chrome ข้ามการเปิดแอป เก็บกุญแจแบบเข้ารหัสและเริ่มตัวรับเอง ส่วนขยายเชื่อมกลับเมื่อแอปกลับมา session ใหม่ไม่เล่นคำสั่งเก่าซ้ำ เพิ่มเมนูลืมการจับคู่เพื่อเพิกถอนรหัสเดิม

อัปเดตแอปแล้ว Reload ส่วนขยาย จับคู่และเปิดจำ Chrome อีกครั้งหนึ่ง จากนั้นเปิดใหม่ไม่ต้องใส่รหัสซ้ำ สิทธิ์ Chrome ครั้งแรกยังต้องกดอนุญาต ไม่อ่านหน้า/จับจอเองขณะ reconnect และไม่เชื่อมหน้าลับ

คงนิสัย โมเดล และสิทธิ์งานอื่น ชุดฝึกโมเดลเล็กเป็นการทดลองเดิม ไม่ได้เปลี่ยนน้ำหนัก Gemini ผ่าน native Windows safeStorage, broker/extension, chat/menu/browser/player และ Test Lab ก่อนสร้างตัวติดตั้ง
