Caprii 0.8.15

เล่นต่อ/หยุด/ข้าม/เพลงก่อนหน้าผ่านแอป Spotify บน Windows โดยตรง ไม่ต้องเชื่อม Chrome ไม่ส่ง Space หรือ media key ไปโปรแกรมอื่น ตรวจ Windows session ของ Spotify เท่านั้น ไม่มี session จะเปิดแอปหนึ่งครั้งสำหรับคำสั่งเล่น

เปิดแอป Spotify และเล่นเพลงหนึ่งครั้งก่อน จากนั้นกดหยุดไว้แล้วสั่ง Caprii ได้ สถานะที่ยืนยันคือ Windows PlaybackStatus/การเปลี่ยนเพลง ยังตรวจเสียงลำโพงไม่ได้ ชื่อเพลง/เพลย์ลิสต์/Liked Songs ยังใช้เว็บเดิม ปิดสวิตช์ Spotify Windows ในเมนู Chrome และเพลงเพื่อใช้เว็บได้

แก้ข้อความสถานะซ้ำ แสดงเวอร์ชันในหัวแชต เก็บการจับคู่และนิสัยเดิม ตรวจ Windows PowerShell/WinRT แบบ read-only และชุดทดสอบจำลอง ไม่ได้ทดสอบบัญชี Spotify จริงของผู้ใช้
