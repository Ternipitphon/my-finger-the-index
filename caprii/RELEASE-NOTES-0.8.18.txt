# Caprii 0.8.18 / Test Lab 1.26.0 — เล่นเพลงชื่อตรงบนสุด

สั่ง “เล่น weathergirl” โดยไม่ระบุศิลปิน เลือกผลเพลงชื่อตรงบนสุดตามตำแหน่งจริงในรายการ Spotify ถ้าระบุศิลปินจะกรองตามศิลปินก่อนแล้วเลือกผลแรก ชื่อซ้ำไม่ทำให้ต้องถามกลับ ลำดับนี้ไม่ใช่หลักฐานยอดฟังสูงสุดหรือคุณภาพดีที่สุด

ระหว่างคุยเรื่องฟังเพลงหรือเมื่อ Caprii ถามชื่อเพลง พิมพ์แค่ชื่อเพลงให้ AI ตีความเป็นเล่นเพลงได้ ไม่ใช้กฎให้ทุกข้อความธรรมดากลายเป็นคำสั่งเพลง ไม่เปลี่ยนคำถามเกี่ยวกับเพลงให้เป็นคำสั่งเล่น

อ่านผลผ่าน Windows UI Automation ตรวจลำดับ ผลและอายุหน้าต่างก่อน Invoke ครั้งเดียว จากนั้นยืนยันชื่อเพลง ศิลปินของแถวที่เลือก และ Windows Playing สองครั้ง ถ้าผลบนสุดไม่มีปุ่มที่เรียกได้จะหยุด ไม่แอบข้ามไปผลล่าง ไม่มี Space หรือคลิกพิกัด การค้นในแอปยังทดลอง ต้องลองกับ Spotify จริง ชุด CI ตรวจตรรกะจำลองและ PowerShell ไม่ได้ใช้บัญชี Spotify จริง ไม่อ้างเสียงลำโพงหรือผลทดสอบ Spotify จากหน้าเว็บ Lab เพลย์ลิสต์/Liked Songs ยังใช้เว็บ เล่นต่อ/หยุด/ข้ามเดิมคงอยู่
