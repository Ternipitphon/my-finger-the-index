## Caprii 0.7.3 — จำการเชื่อม Chrome

ในส่วนขยาย ติ๊ก **จำการเชื่อม Chrome และตามแท็บใช้งาน** แล้วอนุญาตเว็บไซต์ http/https ครั้งเดียว ใส่รหัส Caprii แล้วเชื่อม ระบบจำรหัสเฉพาะบนเครื่อง เชื่อมแท็บที่ใช้งานใหม่อัตโนมัติเมื่อปิดแท็บเดิม หรือปิด–เปิด Chrome ขณะที่แอป Caprii รอบเดิมยังเปิดอยู่ ไม่ต้องใส่รหัสทุกแท็บ

โหมดนี้เป็นตัวเลือก ต้องยอมรับสิทธิ์เว็บไซต์ใน Chrome ก่อน ควบคุมแท็บปัจจุบันครั้งละหนึ่งแท็บ ไม่อ่านทุกแท็บหรือฉีด DOM script เพียงเพราะสลับแท็บ ไม่ติดตามหน้าลับหรือ chrome:// และไม่ย้ายงานที่กำลังทำไปแท็บอื่น กด **ตัดการเชื่อมต่อ** เพื่อลบรหัสที่จำไว้และถอนสิทธิ์เว็บไซต์ หากปิด–เปิดแอป Caprii ใหม่ต้องเชื่อมรหัสใหม่หนึ่งครั้ง

อัปเดตแอปและส่วนขยายเป็น 0.7.3: ปิดแอปเก่าจากถาดระบบ ติดตั้งใหม่ กด Reload ส่วนขยายใน chrome://extensions เปิด Spotify ที่ล็อกอิน แล้วเปิด popup ติ๊กโหมดจำ Chrome และอนุญาตสิทธิ์ เมื่อเชื่อมแล้วสั่ง “เล่นเพลงใน Liked Songs”

## 0.7.1 — ตัวส่งคำสั่งเบื้องหลัง
อัปเดตแอปและ reload ส่วนขยายเป็น 0.7.1 แล้วเชื่อมแท็บใหม่หนึ่งครั้ง Popup ตรวจรหัส/session กับแอปจริงก่อนแสดงสถานะ ตัว worker ใช้ activeTab/scripting/storage เดิม รับคำสั่งและเรียก DOM ในแท็บที่เลือกโดยไม่ใช้ page polling timers ตัดการเชื่อมเมื่อออกคนละ origin หรือปิดแท็บ ไม่กดคำสั่งซ้ำหลังทำแล้วแต่ไม่ได้รับ ack

# เชื่อมแท็บ Chrome ให้ Caprii อ่านและกรอกโดยตรง

1. ติดตั้ง Caprii 0.5.8 แล้วคลิกขวาตัวละคร → **เปิดโฟลเดอร์ส่วนขยาย Chrome**
2. เปิด `chrome://extensions` เปิด **Developer mode** แล้วเลือก **Load unpacked** เลือกโฟลเดอร์ที่เปิดจากข้อ 1 ซึ่งมี `manifest.json` อยู่ ไม่เลือกไฟล์ ZIP
3. คลิกขวา Caprii → **เชื่อมแท็บ Chrome…** แล้วคัดลอกรหัส รหัสนี้ใช้เฉพาะรอบที่เปิด Caprii และไม่ใช่คีย์ Gemini
4. เปิดหน้าเว็บที่ต้องการ กดไอคอนส่วนขยาย Caprii วางรหัส แล้วเลือก **อนุญาตให้ใช้แท็บนี้**
5. กลับมาคุยกับ Caprii เช่น **ทำโจทย์บนหน้าเว็บนี้ กรอกคำตอบ แล้วกดส่งให้หน่อย**

ส่วนขยายอ่านและควบคุมเฉพาะแท็บที่คุณเลือกเชื่อม ไม่ขอสิทธิ์อ่านทุกเว็บไซต์ ข้อมูลที่อ่านอาจส่งให้ผู้ให้บริการ AI ตามการตั้งค่าใน Caprii ควบคุมการยืนยันจากเมนูโหมดไม่ถามของ Caprii ได้เหมือนเดิม

หากรีโหลด เปลี่ยน URL ปิดแท็บ ปิด Chrome หรือเปิด Caprii ใหม่ ให้เชื่อมใหม่ ปิดสิทธิ์ได้จากปุ่ม **ตัดการเชื่อมต่อ** ในส่วนขยาย หยุดงานปัจจุบันด้วยปุ่มหยุดหรือ Ctrl+Alt+Esc

เมื่ออัปเดต Caprii ให้กดปุ่ม Reload ของส่วนขยายใน chrome://extensions ก่อนเชื่อมใหม่ ไม่ใช้กับ chrome://, หน้าไฟล์ในเครื่อง, ช่องรหัสผ่าน, ช่องอัปโหลดไฟล์ หรือเนื้อหาภายใน iframe ที่ไม่ได้เลือก ส่วนขยายไม่ข้าม CAPTCHA และไม่เปลี่ยนสิทธิ์ผู้ดูแลระบบ

การทดสอบอัตโนมัติครอบคลุมการเชื่อมต่อที่มีรหัส การยกเลิก คำสั่ง DOM และฟอร์มจริงใน Electron บน Linux ยังต้องทดสอบการติดตั้งส่วนขยายใน Chrome บน Windows ของคุณ

รุ่น 0.5.5 เติมรหัสจากรอบ browser session เดิมให้อัตโนมัติ และแสดงชื่อแท็บที่เคยเลือก หลังรีเฟรช/นำทางให้เปิด popup แล้วกดอนุญาตอีกครั้ง ไม่ต้องคัดลอกรหัสใหม่ทุกครั้ง เว้นแต่ปิดเปิด Caprii ใหม่ ปุ่มตัดการเชื่อมต่อล้างรหัสด้วย

รุ่น 0.5.8 แยกข้อความผิดพลาดแอปไม่พร้อม รหัส/รุ่นส่วนขยายไม่ตรง และ session หมดอายุ ถ้าหน้าเป็น file:// ให้เปิด Test Lab จากเมนูแอปและใช้แท็บ http แทน ไม่ต้องปิดระบบความปลอดภัยของ Chrome

## 0.7.0 Spotify และการย้ายหน้า
รีโหลดส่วนขยายจากโฟลเดอร์ของแอปรุ่น 0.7.0 แล้วเชื่อมแท็บ open.spotify.com ที่ล็อกอินไว้ การย้ายหน้าใน origin เดิมคง session และ inject ตัวอ่านใหม่เมื่อเอกสารโหลดเสร็จ ออกจาก origin เดิมจะ disconnect ต้องเชื่อมใหม่เมื่อกลับมาจาก login คำสั่งสื่ออนุญาตเฉพาะค้นหา/เพลง/เพลย์ลิสต์/คลังในแท็บ Spotify ที่เลือก ไม่อ่านบัญชีอื่นหรือส่งรหัสผ่าน ไม่เพิ่ม host permissions
