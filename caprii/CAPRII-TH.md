# Caprii 0.5.0 — คู่มือภาษาไทย

## ติดตั้งและเริ่มใช้

ปิด Caprii ตัวเดิมก่อนติดตั้ง ดาวน์โหลด ZIP ทั้ง repository แล้วแตกไฟล์ เปิด `downloads/Caprii-0.5.0/INSTALL-CAPRII.cmd` โดยให้ไฟล์ part01–03 อยู่ข้างกัน สคริปต์ตรวจ SHA256 ทุกส่วน รวมตัวติดตั้ง แล้วเปิดติดตั้ง Windows 10/11 x64 ไม่ต้องติดตั้ง Node.js

หากขึ้น Error opening file for writing ให้ปิด Caprii จากถาดระบบหรือ Task Manager แล้ว Retry อย่ากด Ignore ตัวติดตั้งไม่มีลายเซ็นดิจิทัล และการติดตั้งจริงบน Windows ยังต้องตรวจบนเครื่องคุณ

เมนูอยู่ที่คลิกขวาตัวละครหรือไอคอนถาดระบบ กด Ctrl+Alt+C เพื่อซ่อน/แสดง และ Ctrl+Alt+Esc เพื่อหยุดงานทันที

## ภาษาไทยและเสียงพูด

บทพูดสำเร็จรูป 477 รายการ เมนูหลัก และคำตอบตั้งเป็นไทย คงเลขอารบิก ชื่อโปรแกรม โค้ด URL และรายละเอียดเทคนิคตามจริง หากโมเดลตอบเป็นอังกฤษล้วน จะขอเรียบเรียงไทยเพิ่มได้หนึ่งครั้ง ภายใต้งบคำขอ/เวลาที่จำกัด ไม่แสดงคำตอบอังกฤษล้วนเป็นคำตอบทั่วไปเมื่อแปลงไม่สำเร็จ

เปิด **อ่านบทพูดด้วยเสียงไทย** จากเมนูได้ ต้องมีเสียงไทยแบบ local ติดตั้งในระบบ หากไม่มีเสียงไทย จะแสดงข้อความไทยแทน ไม่ใช้เสียงอังกฤษหรือบริการอ่านเสียงออนไลน์แทน ปุ่มปิดเสียงยังมีผล

## เชื่อม Chrome เพื่อกรอกช่องโดยตรง

1. คลิกขวา Caprii → **เปิดโฟลเดอร์ส่วนขยาย Chrome**
2. เปิด `chrome://extensions` เปิด Developer mode → Load unpacked → เลือกโฟลเดอร์ที่เปิดในข้อ 1
3. คลิกขวา Caprii → **เชื่อมแท็บ Chrome…** → คัดลอกรหัส
4. เปิดแท็บโจทย์ คลิกส่วนขยาย Caprii วางรหัส → **อนุญาตให้ใช้แท็บนี้**
5. สั่ง **ทำโจทย์บนหน้าเว็บนี้ กรอกคำตอบ แล้วกดส่งให้หน่อย**

ส่วนขยายอ่านช่อง/ปุ่มจาก DOM ของแท็บที่เลือก จึงลดการเดาพิกัดและรองรับการอ่านค่ากลับหลังกรอก หากช่อง read-only จะรายงานให้ใช้แป้นคำตอบบนเว็บ กรอกไม่ติดหรือค่าถูกล้างจะไม่รายงานว่าตรวจผ่าน

รหัสเชื่อมมีอายุเฉพาะรอบที่เปิด Caprii ไม่ใช่คีย์ Gemini ไม่ส่งรหัสในแชต ส่วนขยายไม่ขอสิทธิ์อ่านทุกเว็บไซต์ ข้อมูลแท็บที่เลือกอาจส่งให้ผู้ให้บริการ AI ที่ตั้งไว้ ตัดการเชื่อมต่อจากส่วนขยายได้ หากรีโหลด/เปลี่ยน URL/ปิดแท็บหรือเปิด Caprii ใหม่ ต้องเชื่อมใหม่ เมื่ออัปเดต Caprii ให้ Reload ส่วนขยายใน chrome://extensions ด้วย

ฟังก์ชันนี้ไม่ควบคุมแท็บอื่น หน้า chrome:// หน้าไฟล์ในเครื่อง iframe ข้ามเว็บไซต์ ช่องรหัสผ่าน หรืออัปโหลดไฟล์ ไม่ข้าม CAPTCHA และไม่เปลี่ยนสิทธิ์ผู้ดูแลระบบ

## การทำโจทย์และตรวจผล

ใช้เครื่องคิดเลขจำนวนตรรกยะจริงและตัวแก้ปริศนาตรวจเลข ไม่ใช้คำตอบเดา ปริศนาเลขใช้เลขที่เห็นแต่ละตัวครั้งเดียว รองรับ + − × ÷ วงเล็บ และต่อเลขเฉพาะกติกาที่อนุญาต หากไม่พบคำตอบจะรายงานขอบเขต ไม่แต่งเลขใหม่

คำสั่งกรอก/ส่งต้องมีหลักฐานเรียกเครื่องมือครบ การคำนวณสำเร็จอย่างเดียวไม่ถือว่างานจบ ตรวจค่าช่องหลังกรอก และตรวจข้อความตอบรับหลังส่ง การตรวจชื่อหน้าต่างหรือส่งคลิกได้ไม่ยืนยันว่าเว็บรับคำตอบแล้ว หากติดขัดจะรายงานงานที่ยังไม่ทำ

## การยืนยันและหยุดงาน

ค่าเริ่มต้นถามก่อนทำงาน หากต้องการลดการถาม เปิด **โหมดไม่ถาม: ดูจอ/คลิก/พิมพ์/เปิดเว็บ (จนปิด Caprii)** จากเมนูด้วยตัวเอง สิทธิ์นี้อยู่เฉพาะรอบที่เปิดโปรแกรม ไม่เก็บข้ามครั้ง ไม่เปิดการดูจอเป็นพื้นหลัง ไฟล์/สคริปต์และการเปลี่ยนกติกาโจทย์ยังยืนยันแยก แต่ละงานไม่เกิน 5 นาที หยุดจากหน้าต่างติดตามงานหรือ Ctrl+Alt+Esc ได้

## AI และความจำ

ตั้งผู้ให้บริการและคีย์ผ่านหน้า setup ของแอป ไม่ใส่คีย์ในซอร์สหรือแชต การเก็บคีย์ใช้ secure storage ของระบบหรือ environment binding ที่รองรับ ไม่รับประกันโควตา/ความพร้อมของผู้ให้บริการ โมเดลที่รองรับภาพจำเป็นสำหรับการอ่านจอแบบภาพ แต่ทาง Chrome DOM อ่านข้อความ/ช่องโดยตรงได้

ไม่ได้เพิ่ม Memory ข้ามงาน ประวัติแชตไม่บันทึกข้ามการเปิดโปรแกรมเป็นค่าเริ่มต้น การเชื่อมแท็บและรหัสอยู่ในหน่วยความจำเฉพาะรอบ
