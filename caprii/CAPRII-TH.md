# Caprii Agent 0.4.8

แชตภาษาไทย + Project Agent + Browser Agent + เครื่องมือควบคุม Windows แบบขออนุญาต
ไม่มี Memory ของ Agent ข้ามงาน และไม่บันทึกประวัติแชตข้ามการเปิดแอปเป็นค่าเริ่มต้น ไม่ลบข้อมูลเดิมของ Capri ที่อาจมีอยู่ก่อน

## ติดตั้งบน Windows 10/11 x64

ใช้ `Caprii-Agent-Setup-0.4.8.exe` ปิด Capri/Caprii เดิมก่อนติดตั้ง โปรแกรมติดตั้งในโฟลเดอร์เฉพาะ `%LOCALAPPDATA%\Programs\CapriiAgent` และสร้าง shortcut ให้ ไม่ต้องติดตั้ง Node.js สำหรับตัว installer

ตัวติดตั้งไม่มีลายเซ็นผู้พัฒนา Windows อาจแจ้งเตือน SmartScreen รุ่นนี้สร้างใน Linux แต่ยังไม่ได้ทดสอบติดตั้งและควบคุมหน้าจอบน Windows จริง ตรวจ SHA-256 กับไฟล์ SHA256SUMS.txt ที่ส่งมาด้วยก่อนใช้งาน

หากใช้ source: แตก ZIP ในโฟลเดอร์ใหม่ เก็บโปรเจกต์เดิมเป็นสำรอง ใช้ Node.js 20 ขึ้นไป แล้วเปิด `scripts\Start-Caprii.cmd` หรือรัน `npm ci` และ `npm start`

## ตั้งค่า Gemini

เลือก Google Gemini ในเมนู AI และใส่ API key ผ่านหน้า setup ของแอปบน Windows โดยไม่ใส่ใน source/แชต/ภาพหน้าจอ แอปจะตรวจรายชื่อโมเดลและลองตอบจริงก่อนบันทึกการตั้งค่า ใช้ Windows DPAPI ผ่าน Electron safeStorage เก็บ key แบบเข้ารหัส หาก secure storage ไม่พร้อม แอปจะปฏิเสธการบันทึก key เป็น plaintext (ใช้ environment variable ของ provider ได้)

`models/gemini-3.5-flash-lite` ตอบภาษาไทย บริบทต่อเนื่อง และภาพทดสอบได้ในการตรวจวันที่ 30 ตุลาคม 2026 ไม่รับประกันโควตาฟรีหรือความพร้อมในอนาคต ค่าเริ่มต้นเรียง stable Flash Lite ก่อนโมเดลอื่น คุณยังเปลี่ยนโมเดลเองได้ รายการโมเดลอย่างเดียวไม่ได้ยืนยันว่าจะตอบสำเร็จทุกครั้ง

แชตแต่ละคำขอมีเวลารวม 30 วินาที เรียกโมเดลได้สูงสุด 3 ครั้งรวม fallback ไม่ลองซ้ำเมื่อมีคำตอบบางส่วนแล้ว ปุ่มส่งจะเปลี่ยนเป็น **หยุด** ระหว่างรอ คุณยังปิดแชตหรือกด Ctrl+Alt+Esc เพื่อส่งคำขอหยุดได้

## ใช้ Agent

พิมพ์ เช่น:

`/agent เปิดโปรเจกต์นี้ใน VS Code ตรวจโค้ด แก้บั๊ก รันทดสอบ แล้วสรุปเป็นภาษาไทย`

หรือ:

`/agent เปิด http://localhost:3000 กรอกชื่อในฟอร์ม ยืนยัน แล้วตรวจว่าข้อความต้อนรับแสดงจริง`

เลือกโฟลเดอร์งาน อนุญาตให้ส่งคำสั่งให้ AI แล้วตรวจหน้าต่างขออนุญาตของแต่ละเครื่องมือ โดยเฉพาะเนื้อหาก่อน/หลังแก้ไฟล์ คำสั่งจริง และเว็บไซต์/ปุ่มเป้าหมาย ค่าเริ่มต้นของคำถามคือ **ไม่อนุญาต**

หน้าติดตามงานแสดงแผน กิจกรรม สถานะ และหลักฐานการตรวจ คุณกดบันทึกรายงานเป็น JSON ได้เมื่อจบงาน ข้อมูลนี้บันทึกเฉพาะเมื่อคุณเลือกเอง ไม่มีการสร้างความจำส่วนตัวข้ามงาน

### เครื่องมือที่มี

- **โปรเจกต์:** ดูรายการ ค้นหาชื่อ อ่าน สร้าง/แก้ไฟล์ และย้ายไฟล์ภายในโฟลเดอร์ที่เลือก จำกัดไฟล์ 64 KB ไม่อ่าน symlink/ไฟล์ลับที่รู้จัก ไม่เขียนทับปลายทางเมื่อย้าย สำรองต้นฉบับใน `.capri-backups/<task-id>/...` ก่อนแก้/ย้าย ไม่มีเครื่องมือลบไฟล์โดยตรง
- **Coding:** รัน npm scripts ที่มีชื่อ `test`, `build`, `typecheck`, `lint` พร้อมแสดง pre/post scripts ก่อนอนุมัติ จับ exit code จริง หากไม่ผ่านจะส่งผลกลับให้ AI วิเคราะห์และแก้ภายในจำนวนขั้นตอนที่เหลือ
- **Browser:** เปิด HTTPS หรือ HTTP localhost อ่านหน้าและ element IDs กรอกช่องข้อความ คลิก ตรวจข้อความจริงใน DOM และดูภาพหน้าเว็บ ใช้หน้าต่างแยก ไม่มี Node/preload ของแอป ไม่ให้ permission/download/popup การเปลี่ยนไป origin ใหม่ต้องใช้คำสั่งเปิดเว็บและอนุมัติใหม่ ไม่กรอกช่อง password/file ไม่ใช้บัญชีหรือ cookie จากเบราว์เซอร์ส่วนตัว ปิด session และล้างข้อมูลเมื่อจบงาน
- **Vision:** ส่งภาพหน้าจอหรือหน้าเว็บให้โมเดลได้เมื่ออนุมัติ พร้อมข้อมูลแปลงพิกัดภาพเป็นพิกัดจอ
- **Windows:** ดูหน้าต่างและตำแหน่ง เปิด VS Code/Notepad/Explorer โฟกัสหน้าต่าง คลิก พิมพ์ข้อความ Unicode ไทย เลื่อนจอ และใช้ปุ่มที่กำหนด (Enter/Escape/Tab/Backspace/Ctrl+A/S/C/V/Z/Alt+Tab) ต้องเลือก window handle ที่เคยตรวจพบก่อนส่ง input จะโฟกัสเป้าหมายซ้ำหลังปิดคำถามอนุญาต จับภาพและอ่านสถานะจริงหลังแต่ละการกระทำให้ AI ตรวจต่อ คำสั่งส่ง input สำเร็จไม่ได้แปลว่าเป้าหมายงานสำเร็จ

### หยุดและข้อจำกัด

กด **หยุดงาน** ในหน้าติดตามงาน หรือ **Ctrl+Alt+Esc** ได้ทุกเมื่อ ปิดหน้าติดตามงานจะยกเลิกงานที่ยังทำอยู่ด้วย ระหว่าง native dialog ให้กดยกเลิกหากยังเปิดอยู่

งานมีเพดาน 40 ขั้นตอน/5 นาที สคริปต์หนึ่งครั้งสูงสุด 60 วินาทีและมีเพดาน output การหยุดจะยุติ process tree ของสคริปต์ที่ Agent เริ่ม (Unix process group / Windows taskkill) แอป GUI ที่คุณอนุญาตให้เปิดจะยังเปิดอยู่ และไม่สามารถย้อนผลการคลิก/พิมพ์หรือข้อมูลที่ส่งออกไปแล้วได้

การจำกัด path ของเครื่องมือไฟล์ **ไม่ใช่ sandbox สำหรับ npm scripts หรือ desktop input** สคริปต์ที่อนุมัติอาจเปลี่ยนไฟล์นอกโปรเจกต์ ใช้เครือข่าย หรืออ่านข้อมูลของบัญชี Windows ได้ ไม่ให้ Agent รันโปรเจกต์ที่ไม่น่าเชื่อถือ ไฟล์/เว็บ/ภาพเป็นข้อมูลที่อาจมีคำสั่งหลอก AI ระบบจะระบุว่าไม่ใช่คำสั่งผู้ใช้ แต่คุณยังต้องตรวจการอนุมัติทุกครั้ง

ก่อนอนุญาตภาพหรือข้อมูลให้ AI ให้ปิดข้อมูลส่วนตัว/รหัสผ่าน และอย่าอนุมัติไฟล์ที่มี secrets ระบบกรองชื่อไฟล์ลับที่รู้จัก ไม่สามารถตรวจพบความลับทุกแบบในไฟล์ทั่วไปได้

## ตรวจสอบด้วยตนเอง

- `npm test` — unit/integration tests ที่ไม่ใช้ API key
- `npm run test:electron` — เปิดเบราว์เซอร์ Electron จริง กรอก/คลิก/ตรวจ DOM จับภาพ และทดสอบหน้าติดตามงาน/ปุ่มหยุด ต้องมี graphical session
- `npm run test:windows` — **บน Windows ที่ปลดล็อกจอเท่านั้น** ทดสอบโฟกัส พิมพ์ภาษาไทย Ctrl+A คลิก และภาพจริงกับหน้าต่างทดสอบของเรา ไม่ส่งข้อมูลออกไป AI
- `npm run check:gemini` — ทดสอบ Gemini แก้โค้ด fixture ชั่วคราวและ npm test จริง ต้องมี `GEMINI_API_KEY` และอาจใช้โควตา API
- `npm run dist -- --x64 -c.win.signAndEditExecutable=false` — build installer แบบไม่มีลายเซ็น ใช้ custom NSIS ที่สร้าง uninstaller ตอนติดตั้ง ไม่ต้องใช้ Wine ใน Linux

ใน managed cloud ใช้ proxy และ TLS trust ที่ระบบให้ไว้ สำหรับ Node 24 ตั้ง `NODE_USE_ENV_PROXY=1` กับคำสั่ง API หากจำเป็น โหมด browser ใช้ proxy ที่มีอยู่ด้วย อย่าปิด TLS verification การเปิดเว็บนอก allowlist อาจถูก cloud ปฏิเสธ บน Windows ใช้เครือข่ายของเครื่องคุณ

## สถานะการยืนยัน

ทดสอบ unit/integration, Electron/browser/UI และ live Gemini coding/vision ใน Linux แล้ว ผลและข้อจำกัดที่แน่นอนอยู่ใน VALIDATION.md การทดสอบ user32, DPI หลายจอ และติดตั้ง/ถอนติดตั้งบน Windows จริง **ยังไม่ได้รัน** ไม่มีเครื่อง Windows ต่ออยู่กับ cloud นี้ มีคำสั่งทดสอบและ workflow Windows ที่เตรียมไว้ แต่ workflow จะยังไม่ทำงานจนกว่าจะนำ source นี้เข้า GitHub และเรียกใช้งาน

## แก้ไขใน 0.4.8 — คำสั่งดูจอภาษาไทย

- พิมพ์ **ดูจอให้หน่อย** จะเข้าขั้นตอนขออนุญาตและจับภาพจริง แสดงสถานะว่ากำลังจับภาพ/ส่งภาพ ไม่ส่งเป็นแชตตัวอักษรอย่างเดียว
- พิมพ์ **ดูจอแล้วพิมพ์คำตอบไป** หรือ **ช่วยดูหน้าจอแล้วกรอกคำตอบ** จะเข้า Agent อัตโนมัติ ไม่ต้องใส่ /agent สำหรับคำสั่งกลุ่มนี้ ยังต้องอนุญาตก่อนส่งภาพและส่ง input
- ปุ่มหยุดยกเลิกคำขอวิเคราะห์ภาพได้ จำกัดเวลารวม 30 วินาที
- ปรับคำสั่งบุคลิกให้สุภาพ ไม่กล่าวโทษผู้ใช้ และไม่อ้างว่าเห็นจอถ้ายังไม่ได้รับภาพ
- ตัวช่วย Windows รับโค้ดที่มากับแอปเป็น command และรับข้อมูลคำสั่งแยกทาง stdin จึงไม่ต้องรันไฟล์ .ps1 ผ่าน execution policy ของเครื่อง ไม่เปลี่ยน execution policy
- ยังไม่ทดสอบ Windows user32 บนเครื่องจริงเหมือนเดิม การแก้การเรียกคำสั่งไม่ได้เป็นหลักฐานว่า input จะทำงานได้บน Windows ทุกเครื่อง

หากต้องการทำงานกับ Chrome ที่เปิดอยู่ ให้เลือกคำสั่งดูจอและอนุญาตภาพ หากต้องการ Browser Agent ให้ระบุ URL โดยตรง หน้าต่าง Browser Agent แยกจาก Chrome ของคุณ

## เพิ่มใน 0.4.8 — คำนวณจริง / เมาส์ / YouTube

- พิมพ์ **เปิดyoutube**, **เปิด YouTube ให้หน่อย** หรือ **เปิดยูทูป** ได้ จะถามยืนยันแล้วเรียกเบราว์เซอร์เริ่มต้นโดยตรง ไม่ต้องรอคำตอบจาก AI การส่งคำขอเปิดไม่ได้รับรองว่าเครือข่ายโหลดหน้าเว็บสำเร็จ
- คำสั่ง **คลิกปุ่มส่ง**, **ใช้เมาส์ลาก…**, **คลิกขวา…**, **ดับเบิลคลิก…**, **เลื่อนลง**, **พิมพ์…** เข้า Agent ได้โดยไม่ต้องใส่ /agent ต้องตรวจและอนุญาตการกระทำก่อนดำเนินการ
- ตอนเริ่ม Agent เลือก **ทำงานบนจอ/เว็บ** ได้โดยไม่ต้องเลือกโฟลเดอร์ ในโหมดนี้ไม่มีเครื่องมืออ่าน/เขียน/รันสคริปต์ของโปรเจกต์ หากต้องแก้โค้ดให้เลือก **เลือกโฟลเดอร์โปรเจกต์**
- เพิ่มเมาส์เลื่อนตำแหน่ง คลิก ดับเบิลคลิก คลิกขวา ลากวาง และปุ่มลัดเพิ่ม เช่น Ctrl+L/F/W ลูกศร Home/End/PageUp/PageDown ต้องมีภาพจอล่าสุดและ target window ที่ตรวจพบก่อนส่ง input หากต้องคลิกเมนูนอกขอบหน้าต่าง ต้องยืนยัน allowOutsideWindow โดยชัดเจน
- เครื่องมือคณิตใช้เศษส่วนแบบ exact ไม่ใช้ eval: ตรวจนิพจน์ + − × ÷ และวงเล็บได้ คิดหลายข้อในครั้งเดียวด้วย math.batch ได้ เกมใช้เลขครบครั้งเดียวตรวจด้วย math.solve/math.verify รวมการต่อเลขเฉพาะเมื่อกฎอนุญาต ไม่รองรับยกกำลัง/แฟกทอเรียล/รากในตัวตรวจเกมรุ่นนี้
- งานที่ขอคำนวณ/กรอกคำตอบจะปฏิเสธการพิมพ์ค่าที่ไม่มีหลักฐานจากตัวคำนวณ รวมคำอ่านตัวเลข และแสดงผลคำนวณที่ตรวจจริงในรายงาน หากไม่พบคำตอบจะรายงานเฉพาะกฎที่ตรวจ ไม่เดาเลขใหม่ การอ่านภาพหรือจับคู่ผลกับช่องยังอาจผิดได้ ต้องตรวจการอนุมัติและผลหลังส่ง

### ตรวจเมาส์บนเครื่องคุณ

คลิกขวาตัวละครหรือไอคอน tray ตรวจว่าขึ้น **Caprii 0.4.8** แล้วเลือก **ทดสอบเมาส์และการพิมพ์** เครื่องจะขออนุญาต จากนั้นทดสอบพิมพ์ไทย/เลข เลือกข้อความ คลิก ดับเบิลคลิก คลิกขวา และลากวางในหน้าต่างทดสอบของแอปเอง ไม่มี API key/Node.js เพิ่มเติม และไม่ส่งภาพไป AI อย่าเปลี่ยนหน้าต่างระหว่างทดสอบ ปิดหน้าต่างหรือ Ctrl+Alt+Esc เพื่อหยุดได้

เมนูทดสอบนี้ต้องรันบน Windows จริง จึงยังไม่มีผลผ่านจาก cloud Linux หากไม่ผ่าน ให้เก็บภาพข้อความผิดพลาดในหน้าต่างทดสอบไว้เพื่อวิเคราะห์ ไม่ควรสั่งให้คลิกแบบอัตโนมัติต่อ

รุ่นนี้ไม่รับรองการควบคุมได้ทุกโปรแกรม เช่น หน้าจอ UAC โปรแกรมสิทธิ์สูงกว่าเกม/โปรแกรมที่ป้องกัน input หรือ CAPTCHA ยังมีข้อจำกัด ไม่ข้ามระบบป้องกันเหล่านั้น


## เวอร์ชัน 0.4.8

เพิ่มปุ่ม “อนุญาตตลอดงานนี้” สำหรับจอหรือหน้าต่างที่เลือก สิทธิ์อยู่ในหน่วยความจำเฉพาะงาน ไม่เกิน 5 นาที จบงานหรือหยุดแล้วหมดสิทธิ์ การคลิกอาจส่งแบบฟอร์มหรือแก้ข้อมูลได้ เปลี่ยนหน้าต่าง/จอหรือใช้คำสั่งที่ไม่อยู่ในขอบเขตจะถามใหม่

ตัวละครเริ่มกลางจอ แล้วสุ่มเลื่อนเดิน ขยับ และแสดงข้อความไทยเมื่อว่าง หยุดพฤติกรรมสุ่มระหว่างเปิดแชตหรือทำงาน ไม่สุ่มควบคุมเมาส์หรือเปิดโปรแกรม

การติดตั้งทับ: ปิด Caprii ที่ถาดระบบก่อนเริ่มติดตั้ง Windows และการคลิกจริงต้องตรวจบน Windows ไม่ถือว่าทดสอบแล้วบน Linux
