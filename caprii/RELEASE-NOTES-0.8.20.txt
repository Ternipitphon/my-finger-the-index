# Caprii 0.8.20 / Test Lab 1.28.0 — ท่าทางประกอบงานจริง

เชื่อมท่าดั้งเดิมกับสถานะการคุย งาน Agent เพลง รูปและดูจอ: ระหว่างรอใช้ curious/look และแยกร่างสั้นเป็นระยะ รอคำตอบ/อนุญาตหยุดท่าทำงานและใช้ curious งาน media/agent ต้อง verified true จึง hop; Agent ที่ผ่านและใช้เวลาตั้งแต่สองนาทีใช้ victory ข้อผิดพลาดใช้ flinch แค่เปิดเบราว์เซอร์หรือ AI เลือกเครื่องมือยังไม่ถือว่าทำงานสำเร็จ

เพิ่มสวิตช์ ท่าทางประกอบงาน AI ในคลิกขวา → ตัวละครและหน้าจอ → ลูกเล่นตัวละคร ปิดได้อิสระจากการดูจอ ปิดแชต หยุดงาน ซ่อนตัว ปิดท่า หรือปิด auto-look ระหว่างรอ จะไม่เล่นท่าจากผลเก่า ท่าลดการเคลื่อนไหวตาม Windows/ตัวเลือกเดิม ไม่บังคับย้ายตัวละครหรือยึดเมาส์

ไม่ได้เพิ่มการจับภาพ การส่งภาพ การเรียก AI สิทธิ์ หรือการลองคำสั่งซ้ำ วิธีดูจอ สวิตช์ดูจอ และการยินยอมเดิมคงอยู่ มองดาวเทียม เดโม เข้าสิงหน้าต่าง หลับ/เก็บตัวและลูกเล่นเดิมคงเดิม เรียกดาวเทียม/เดโมเองมีลำดับสำคัญเหนือท่าประกอบงาน ไม่สุ่มฉากใหญ่ทุกคำตอบ

ทดสอบ lifecycle กับ Chat จริงและผลเครื่องมือจำลอง รวมผลช้า/ยกเลิก คำสั่งไม่ verified และการคงสิทธิ์ดูจอ ตรวจบูต Electron และเมนู Windows เดิม หน้าเว็บ Lab ไม่อ้างคะแนนท่าทางหรือความสำเร็จ Spotify จริง
